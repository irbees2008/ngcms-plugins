# CSV News Re-import

Плагин обновляет дополнительные поля уже существующих новостей по данным CSV.
Записи ищутся по точному заголовку новости; новые новости не создаются.

## Использование

1. Откройте страницу настройки плагина и загрузите CSV-файл.
2. Нажмите «Обновить новости» напротив загруженного файла.
3. В уведомлении будет указано количество обновленных новостей, ненайденных
   заголовков, ошибочных и пустых строк.

Файлы хранятся в `engine/plugins/csv_reimport/upload/`. Каталог создается
автоматически и должен быть доступен для записи веб-серверу.

## Формат CSV

- Разделитель колонок: точка с запятой (`;`).
- Поддерживаются кодировки UTF-8 и Windows-1251.
- Требуется не менее восьми колонок; строка заголовков необязательна.
- Первая колонка игнорируется.
- Во второй колонке должен находиться заголовок новости, совпадающий с
  заголовком в базе данных.
- Колонки 3–8 содержат значения xfields в порядке:
  `gosreg`, `refusalfire`, `refusal`, `conformity`, `voluntaryfire`, `roomab`.

Уже заполненные xfields сохраняются. Изображения не перезаписываются.
Если среди новостей есть одинаковые заголовки, обновляется запись с наименьшим
ID. Для работы импорта необходим активный плагин `xfields`.
