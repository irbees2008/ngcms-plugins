# Личные сообщения

Плагин реализует возможность обмена приватными сообщениями между
зарегистрированными пользователями на вашем сайте.

## Функции

- Отправка и удаление сообщений.
- Папки «Входящие» и «Исходящие».
- Уведомление о приходе нового сообщения.
- Поддержка BB-кодов.

## Установка

1. Скопируйте папку плагина в `/engine/plugins/`.
2. Установите и включите плагин в админ-панели в разделе «Плагины».

После активации личные сообщения доступны по адресу `/plugin/pm/`.

## Переменные шаблона usermenu.tpl

- `{{ p.pm.pm_unread }}` — количество новых входящих сообщений.
- `{{ p.pm.pm_all }}` — общее количество входящих сообщений.
- `{{ p.pm.link }}` — URL страницы входящих сообщений.

Пример:

```twig
{% if p.pm.pm_unread != 0 %}
  <a href="{{ p.pm.link }}">Новые сообщения: {{ p.pm.pm_unread }}</a> /
{% endif %}
{{ p.pm.pm_all }}
```

## Ссылка на отправку сообщения из профиля

Плагин подставляет имя получателя, если передать его в URL параметром `?action=write&name=nickname`. Чтобы добавить ссылку «Отправить сообщение» в шаблон `/plugins/uprofile/users.tpl`, используйте:

```html
<a href="/plugin/pm/?action=write&name={user}">[Отправить сообщение]</a>
```

## Шаблоны плагина

Оформление находится в файлах `.tpl` и `.css`.

### `inbox.tpl` — входящие сообщения

- `php_self` — ссылка на страницу плагина вида `site.ru/plugin/pm/`.
- `pagination` — навигация по страницам.
- В цикле `{% for entry in entries %}` доступны:
  - `pmdate` — дата и время отправки сообщения.
  - `php_self` — ссылка на страницу плагина.
  - `pmid` — ID сообщения в БД.
  - `subject` — тема сообщения.
  - `link` — ссылка на отправителя.
  - `viewed` — изображение статуса (`viewed.yes.gif` или `viewed.no.gif`).

### `outbox.tpl` — исходящие сообщения

- `php_self` — ссылка на страницу плагина вида `site.ru/plugin/pm/`.
- `pagination` — навигация по страницам.
- В цикле `{% for entry in entries %}` доступны:
  - `pmdate` — дата и время отправки сообщения.
  - `php_self` — ссылка на страницу плагина.
  - `pmid` — ID сообщения в БД.
  - `subject` — тема сообщения.
  - `link` — ссылка на получателя.

### `read.tpl` — чтение сообщения

- `php_self` — ссылка на страницу плагина.
- `subject` — тема сообщения.
- `pmid` — ID сообщения в БД.
- `location` — `inbox` или `outbox`.
- `pmdate` — дата и время отправки сообщения.
- `content` — текст сообщения.
- `author` — ссылка на получателя или отправителя.

### `reply.tpl` — ответ на сообщение

- `php_self` — ссылка на страницу плагина.
- `title` — тема сообщения с префиксом `Re`.
- `pmid` — ID сообщения в БД.
- `to_username` — ID отправителя из таблицы `users`.
- `quicktags` — форма с BB-тегами.
- `smiles` — форма со смайлами.

### `write.tpl` — новое сообщение

- `php_self` — ссылка на страницу плагина.
- `username` — имя получателя.
- `quicktags` — форма с BB-тегами.
- `smiles` — форма со смайлами.
