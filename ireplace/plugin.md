# Замена подстрок в базе данных

Плагин позволяет заменять подстроки в следующих типах содержимого:

- **Новости** — содержимое новости.
- **Статические страницы** — содержимое страницы.
- **Комментарии** — текст комментария.

После выполнения плагин сообщает количество изменённых объектов.
