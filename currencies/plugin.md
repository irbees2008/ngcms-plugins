# Мультивалютность

**Версия:** 1.0.0  
**Зависимости:** нет; интегрируется с плагинами `basket` и `payments`.

## Описание

Плагин добавляет поддержку нескольких валют. Позволяет отображать цены
в выбранной пользователем валюте с пересчётом по курсам. Курсы обновляются
автоматически (с сайта ЦБ РФ) или задаются вручную.
Интерфейс настроек и управления валютами доступен на русском и английском языках.

## Установка


1. Установите плагин через панель администратора.
   Создаётся таблица `{prefix}_currencies`, в которую автоматически добавляется
   базовая валюта из настроек.
2. Настройте базовую валюту (Плагины → currencies → Настройки).
3. Добавьте остальные валюты в панели управления:
   Плагины → currencies → Управление валютами.
4. Для автоматического обновления курсов настройте системное задание cron,
   вызывающее плагин с параметром `cron`.

## Настройки

| Параметр | Описание |
| --- | --- |
| `base` | ISO-код базовой валюты (`RUB`, `UAH`, `USD`). Все цены хранятся в этой валюте. |
| `rate_source` | Источник курсов: `cbr` (ЦБ РФ, база RUB), `nbu` (НБУ, UAH), `nbk` (НБК, KZT), `ecb` (ЕЦБ, EUR) или `manual` (вручную). |
| `format` | Формат цены: `%s` — сумма, `%c` — символ. Например, `%s %c` выводит `1 234.50 ₽`. |

Автоматическое обновление доступно, если базовая валюта поддерживается выбранным
источником.

## Управление валютами

Для каждой валюты задаются следующие поля:

| Поле | Описание |
| --- | --- |
| `code` | ISO-код, например `RUB`, `USD`, `EUR` или `UAH`. |
| `name` | Название валюты, например «Российский рубль». |
| `symbol` | Символ валюты: `₽`, `$`, `€`, `₴` и т. п. |
| `rate` | Количество единиц целевой валюты за одну единицу базовой валюты. |
| `is_base` | Флаг базовой валюты; её курс всегда `1.0`. |

Например, при базовой валюте RUB курс USD `0.011` означает `1 RUB = 0.011 USD`.

## URL переключения валюты

Адрес `/currencies/switch/?code=USD` переключает валюту пользователя и возвращает
его на страницу-источник. Выбор хранится в cookie в течение одного года.

## Переменные шаблонов

Плагин добавляет на каждую страницу переменные через `add_act('index', ...)`:

| Переменная | Описание |
| --- | --- |
| `{{ currency_active }}` | ISO-код активной валюты пользователя, например `RUB`. |
| `{{ currencies_list }}` | Массив валют из базы данных с полями `id`, `code`, `name`, `symbol`, `rate` и `is_base`. |
| `{{ currency_switch_link }}` | Базовый URL переключателя `/currencies/switch/`. |

## PHP-функции

| Функция | Описание |
| --- | --- |
| `currencies_get_active(): string` | Возвращает ISO-код активной валюты пользователя. |
| `currencies_get_all(): array` | Возвращает все валюты из БД; результат кешируется на время запроса. |
| `currencies_get_rate(string $code): float` | Возвращает курс валюты относительно базовой. |
| `currencies_convert(float $price, string $from, string $to): float` | Конвертирует сумму из одной валюты в другую. |
| `currencies_format(float $price, string $baseCurrency = ''): string` | Форматирует сумму в активной валюте с символом. `baseCurrency` задаёт валюту исходной цены; по умолчанию используется настройка `base`. |

Примеры вызова:

```php
$converted = currencies_convert(1000, 'RUB', 'USD');
$formatted = currencies_format(1000); // Например, «11.00 $» при активной USD
```

## Пример: переключатель валюты

В файле `header.tpl` или `sidebar.tpl`:

```twig
<div class="currency-switcher">
  {% for c in currencies_list %}
    <a href="{{ currency_switch_link }}?code={{ c.code }}"
       class="{% if c.code == currency_active %}active{% endif %}">
      {{ c.symbol }} {{ c.code }}
    </a>
  {% endfor %}
</div>
```

## Пример: отображение цены в активной валюте

В шаблоне новости/товара (если цена берётся из xfield «price»):

`{{ xfields_price }}` — цена в базовой валюте, как она хранится в `xfields`.

Для отображения цены в активной валюте используйте PHP в своём плагине или виджете:

```php
$priceConverted = currencies_format((float)$newsRow['xfields_price']);
```

## Автоматическое обновление курсов

Системный планировщик вызывает функцию `plugin_currencies_cron()`. При
`source = 'cbr'` плагин обращается к
[сайту Банка России](https://www.cbr.ru/scripts/XML_daily.asp) и обновляет курсы
валют, уже добавленных в таблицу `currencies`.

Валюты, отсутствующие в таблице, игнорируются (добавьте их вручную).

## Интеграция с payments

Адаптеры плагина `payments` читают базовую валюту через:

```php
pluginGetVariable('payments', 'currency')
```

Для синхронизации задайте одинаковый ISO-код в настройках обоих плагинов.
