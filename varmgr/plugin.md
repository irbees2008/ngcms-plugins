# Менеджер переменных в новостях

Плагин `varmgr` позволяет гибко настраивать отображение даты в коротких и полных новостях.

## Переменные даты

Плагин добавляет переменные, основанные на дате создания новости:

| Переменная | Значение |
|---|---|
| `{day}` | День месяца без ведущего нуля (`1`–`31`) |
| `{day0}` | День месяца с ведущим нулём (`01`–`31`) |
| `{month}` | Номер месяца без ведущего нуля (`1`–`12`) |
| `{month0}` | Номер месяца с ведущим нулём (`01`–`12`) |
| `{year}` | Год в формате `00`–`99` |
| `{year2}` | Год в формате `1971`–`2099` |
| `{month_s}` | Краткое название месяца (`Янв`, `Фев`, …, `Дек`) |
| `{month_l}` | Полное название месяца (`Январь`, `Февраль`, …, `Декабрь`) |

## Форматирование даты

Плагин может заменить стандартную переменную `{date}` в шаблоне новости. Задайте формат с помощью переменных выше. Например:

```text
{day0}/{month0}/{year2}
```

Для даты 24 мая 2008 года получится `24/05/2008`.
