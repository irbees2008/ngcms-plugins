# ===========================================================================

# NG CMS // Плагины // share

# ===========================================================================

Блок «Поделиться» новостью помогает посетителям быстро публиковать ссылки на
интересные им страницы в социальных сетях и блогах. Что в свою очередь
ускоряет поисковую индексацию. Также плагин позволяет отправить ссылку на новость
по email, мессенджеры или вывести на печать.

## Использование

В шаблоне новости (news.tpl, news.short.tpl, news.full.tpl):

```twig
{{ plugin_share }}
```

## Поддерживаемые сервисы

- Facebook
- X (Twitter)
- ВКонтакте
- Одноклассники
- Telegram
- WhatsApp
- Viber
- Мой мир (Mail.ru)
- LinkedIn
- Pinterest
- Reddit
- Instagram
- Threads
- Печать

## Настройка

В админ-панели плагина можно включить/выключить каждую социальную сеть отдельно.
Также можно выбрать источник шаблонов (плагин или тема) и скин оформления.

## Требования

- NG CMS (Next Generation CMS) 0.9.7+
- Twig 2.x/3.x
- PHP 7.4+
