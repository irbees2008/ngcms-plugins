# AJAX-чат

**Версия:** 0.12  
**Дата документации:** 01.02.2026  
**Требование:** ng-helpers v0.2.2.

Плагин добавляет веб-чат на страницы сайта. Обновление сообщений выполняется
посредством AJAX и JSON, что сокращает объём передаваемых данных.

## Возможности

- Настройка доступа гостей: запрет, просмотр или просмотр с возможностью писать.
- Настройка интервала обновления чата. Рекомендуемое значение — 30 секунд.
- Настройка количества сообщений в истории.
- Защита от флуда.
- Остановка обновлений, если пользователь не отправлял сообщения в течение
  заданного периода. Рекомендуемое значение — 1200 секунд (20 минут).
- Автоматическое разделение длинных слов для сохранения оформления чата.
- Ограничение максимальной длины сообщения.
- При отсутствии новых сообщений передаётся около 20 байт данных (плюс HTTP-заголовки);
  при наличии обновлений передаются только новые сообщения.
- Вывод в боковой панели или на отдельной странице. Отдельная страница может
  отображаться в дизайне сайта или самостоятельно.
- Интеграция с ng-helpers v0.2.2: логирование в `engine/data/logs/plugins.log`,
  очистка пользовательских данных через `sanitize()` и безопасное чтение параметров
  через `array_get()`.
- Панель выбора более чем 190 эмодзи доступна в боковой панели, на отдельной
  странице и в отдельном окне.

## Отображение чата

Добавьте переменную `{{ plugin_jchat }}` в `main.tpl`. Содержимое чата оформляется
шаблоном `jchat.tpl`.

> **Внимание.** Шаблон содержит не только HTML-разметку, но и необходимые для работы
> JavaScript-фрагменты. Комментарии в шаблоне отмечают блоки, которые можно менять
> и которые не следует изменять без понимания последствий.

Формат строки сообщения определяется в `tpl/jchat.script.header.js`, строки 125–139:

```javascript
// **                                                                  **
// ** NOTIFICATION FOR ADMIN                                           **
// ** YOU CAN MAKE CHANGES IN THIS LINE TO CHANGE VIEW OF jChat RECORD **
// **                                                                  **
cell.innerHTML =
	// 1. Поле для отображения даты&времени записи (со стилем float: right)
	'<div style="float: right; font-size: 75%;" title="'+rec['datetime']+'">'+rec['time']+'</div>'+
	// 2. Изображение-признак зарегистрированного пользователя, оно также является ссылкой на профиль пользователя (если включен плагин uprofile)
	((rec['author_id']>0)?('{% if pluginIsActive("uprofile") %}<a target="_blank" href="'+rec['profile_link']+'">{% endif %}<img src="{{ skins_url }}/images/profile.png" width="13" height="13" border="0"/>{% if pluginIsActive("uprofile") %}</a>{% endif %} '):'')+
	// 3. Имя автора [жирным, используется специальный класс jchat_userName для автовставки имени]
	'<span class="jchat_userName">'+rec['author']+'</span>'+
	// 4. Переход на новую страницу
	'<br/> '+
	// 5. Сам текст сообщения
	rec['text'];
```
