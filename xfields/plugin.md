# Дополнительные поля

Плагин `xfields` позволяет создавать собственные поля для новостей и пользователей, группировать поля по категориям и хранить повторяющиеся табличные данные.

## Типы полей

- **Текст** (`text`) — однострочное значение.
- **Текстовый блок** (`textarea`) — многострочное значение; по настройке плагина при выводе переводы строк преобразуются в `<br/>`.
- **Выбор значения** (`select`) — одно значение из списка.
- **Множественный выбор** (`multiselect`) — несколько значений из списка.
- **Флажок** (`checkbox`) — логическое значение.
- **Группа изображений** (`images`) — изображения, прикреплённые к записи, с описаниями и ссылками на оригиналы и превью.

Некоторые типы и параметры доступны только для соответствующего раздела и зависят от конфигурации поля.

## Вывод полей новости в Twig

Данные новостных полей доступны в `p.xfields`, по ID поля. Для обычного текстового поля `summary` выведите значение так:

```twig
{{ p.xfields.summary.value }}
```

Проверить наличие значения и вывести заголовок с ним:

```twig
{% if p.xfields.summary.value %}
  <section class="news-summary">
    <h3>{{ p.xfields.summary.title }}</h3>
    <div>{{ p.xfields.summary.value }}</div>
  </section>
{% endif %}
```

Для каждого поля доступны:

- `p.xfields.ID.type` — тип поля (`text`, `textarea`, `select`, `multiselect`, `checkbox` или `images`).
- `p.xfields.ID.title` — название поля.
- `p.xfields.ID.value` — значение; для поля типа `images` это HTML, сформированный шаблоном `news.show.images.tpl`.

Для поля типа `images` также доступны:

- `p.xfields.ID.count` — количество прикреплённых изображений.
- `p.xfields.ID.entries` — массив изображений.

Чтобы посмотреть доступные значения, используйте Twig-функцию `debugValue`:

```twig
{{ debugValue(p.xfields) }}
```

Если ID поля содержит символы, которые нельзя использовать в точечной записи Twig, обращайтесь к элементу массива по ключу, например `p.xfields['field-name'].value`.

## Вывод группы изображений

В `p.xfields.gallery.entries` каждое изображение содержит:

- `url` — URL оригинала.
- `width`, `height` — размеры оригинала.
- `name` — имя файла.
- `origName` — исходное имя файла при загрузке.
- `description` — описание изображения.
- `flags.hasPreview` — признак существующего превью.
- `purl`, `pwidth`, `pheight` — URL и размеры превью, если оно есть.

Пример независимого Twig-вывода изображений:

```twig
{% if p.xfields.gallery.count > 0 %}
  <div class="news-gallery">
    {% for image in p.xfields.gallery.entries %}
      <a href="{{ image.url }}" title="{{ image.description }}">
        {% if image.flags.hasPreview %}
          <img src="{{ image.purl }}" width="{{ image.pwidth }}" height="{{ image.pheight }}" alt="{{ image.description }}">
        {% else %}
          <img src="{{ image.url }}" width="{{ image.width }}" height="{{ image.height }}" alt="{{ image.description }}">
        {% endif %}
      </a>
    {% endfor %}
  </div>
{% endif %}
```

По умолчанию плагин сам формирует HTML-значение поля `images` через `plugins/xfields/tpl/news.show.images.tpl`. Этот шаблон получает:

- `fieldName`, `fieldTitle`, `fieldType` — ID, название и тип поля.
- `entriesCount` и `entries` — количество и список изображений с описанными выше свойствами.
- `execStyle` — стиль вызова (`short`, `full`, `export`, `export_body`, `export_short` или `export_full`).
- `execPlugin` — ID плагина, инициировавшего вывод; при вызове из ядра пуст.

Чтобы изменить вывод по умолчанию, отредактируйте этот Twig-шаблон в каталоге плагина.

## Ранее загруженные изображения

В форме добавления или редактирования новости можно выбрать изображение, ранее загруженное в любое поле типа «Группа изображений». Выбранное изображение прикрепляется к новой записи как отдельная запись изображения, при этом используется тот же физический файл. Исходная новость и её изображение не удаляются и не изменяются.

При сохранении плагин проверяет наличие файла миниатюры и корректно выбирает каталог общего или персонального хранилища. Если превью отсутствует, оно создаётся, когда у исходного изображения был включён признак превью или в настройках поля включено создание миниатюр. Для уже прикреплённых изображений эта проверка также выполняется при редактировании новости; при создании превью в записи изображения обновляются его размеры и признак наличия.

## Табличные данные новости

Для настроенных табличных полей доступны `p.xfields._table.countRec` (число строк) и `p.xfields._table.data` (массив строк). Шаблон `plugins/xfields/tpl/news.table.tpl` получает массив `entries`; поля строки доступны как `entry.field_ID`, а также `entry.num` и `entry.id`. Для проверки заполненности отдельных значений доступны соответствующие флаги `entry.flags.field_ID`.

Пример:

```twig
{% if p.xfields._table.countRec > 0 %}
  <table>
    <tbody>
      {% for entry in p.xfields._table.data %}
        <tr>
          <td>{{ entry.num }}</td>
          <td>{{ entry.field_model }}</td>
          <td>{{ entry.field_price }}</td>
        </tr>
      {% endfor %}
    </tbody>
  </table>
{% endif %}
```

## Совместимость со старыми шаблонами

В обычных шаблонах NGCMS продолжают поддерживаться legacy-маркеры:

- `[xvalue_ID]` — значение поля.
- `[xfield_ID]...[/xfield_ID]` — содержимое блока, если поле заполнено; для обычного поля значение `0` считается незаполненным.
- `[nxfield_ID]...[/nxfield_ID]` — содержимое блока, если поле не заполнено.

Пример для старого шаблона:

```text
[xfield_summary]
<h3>Кратко</h3>
[xvalue_summary]
[/xfield_summary]
```

Для новых шаблонов рекомендуется Twig-синтаксис из предыдущих разделов.

## Настройка полей

- **ID** — уникальный идентификатор поля; используется в Twig и legacy-маркерах.
- **Название** — подпись поля в форме редактирования записи.
- **Тип** — формат значения и соответствующее поведение поля.
- **Значение по умолчанию** и **Список значений** — используются только для поддерживаемых типов.
- **Обязательно** — требует заполнить поле или выбрать значение перед сохранением.
- **Область** и **Группа** — определяют расположение поля в административной форме и категории новостей, в которых оно доступно.
- Для текстовых полей также настраиваются поддержка HTML и BBCode, а для многострочного текста — форматирование переводов строк.
- Для группы изображений настраиваются максимальное число изображений, создание миниатюры, её размеры, водяной знак и тень.
- **Хранение** позволяет сохранять значение отдельного поля в колонке записи вместо общего массива дополнительных полей.

## Версия 0.34

- Добавлен выбор ранее загруженных изображений для полей типа «Группа изображений».
- При повторном использовании изображения сохраняется ссылка на тот же физический файл, без удаления исходной записи.
- Исправлена обработка изображений из общего и персонального хранилищ.
- Добавлено создание отсутствующей миниатюры и восстановление признака и размеров превью при сохранении или редактировании новости.
- Документация и примеры обновлены для Twig; старые маркеры выделены как режим совместимости.
