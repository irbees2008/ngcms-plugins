# Дополнительные поля

Плагин `xfields` позволяет создавать пользовательские поля для новостей и выводить их значения в шаблонах.

## Поддерживаемые типы полей

- **Текстовое** — строка, вводимая при добавлении или редактировании новости.
- **Выбор значения** — администратор задаёт варианты, из которых выбирают при редактировании новости.
- **Текстовый блок** — многострочный текст; при выводе между строками добавляется HTML-тег `<br/>`.
- **Изображения** — группа изображений с данными для шаблонного вывода.

## Переменные шаблонов

При активации плагина в обычных шаблонах доступны:

- `[xfield_ИМЯ]...[/xfield_ИМЯ]` — блок отображается, если поле с указанным ID заполнено. Значение `0` считается незаполненным.
- `[xvalue_ИМЯ]` — значение поля с указанным ID.

В Twig-шаблонах свойства дополнительных полей доступны в пространстве `p.xfields`. Например, `ИМЯ.type` используется как `p.xfields.ИМЯ.type`.

Для каждого поля доступны:

- `ИМЯ.type` — тип (`text`, `textarea`, `select`, `images`).
- `ИМЯ.title` — название поля.
- `ИМЯ.value` — значение поля, кроме типа `images`.

Для полей типа `images` доступны:

- `ИМЯ.count` — количество изображений.
- `ИМЯ.value` — отрендеренный шаблон `news.show.images.tpl`, если он существует.
- `ИМЯ.entries` — массив изображений; формат описан ниже.

Чтобы посмотреть доступные данные, можно использовать Twig-функцию `debugValue`:

```twig
{{ debugValue(p.xfields) }}
```

## Шаблон изображений `news.show.images.tpl`

Этот Twig-шаблон находится в каталоге плагина и используется для вывода полей типа `images`.

Доступные переменные:

- `fieldName` — ID дополнительного поля.
- `fieldTitle` — название поля.
- `fieldType` — значение `images`.
- `entriesCount` — количество изображений в поле.
- `entries` — массив изображений. Каждый элемент содержит:
  - `flags.hasPreview` — `1`, если у изображения есть уменьшенная копия.
  - `url` — URL изображения.
  - `width`, `height` — размеры оригинала.
  - `name` — имя файла без пути.
  - `origName` — исходное имя файла при загрузке.
  - `description` — описание изображения.
  - Если существует уменьшенная копия: `pwidth`, `pheight` и `purl` — её размеры и URL.
- `execStyle` — режим вызова:
  - `short` — вывод короткой новости.
  - `full` — вывод полной новости.
  - `export` — экспорт данных без обновления счётчиков.
  - `export_body` — экспорт только тела короткой и полной новости.
  - `export_short` — экспорт только тела короткой новости.
  - `export_full` — экспорт только тела полной новости.
- `execPlugin` — плагин, через который выполняется вывод; при вызове из ядра пуст.

## Шаблон таблиц `news.table.tpl`

Для отображения данных из таблиц новостей используется Twig-шаблон `news.table.tpl` в каталоге плагина. Он получает массив `entries`; каждый элемент соответствует строке таблицы.

- `num` — порядковый номер записи.
- `id` — ID записи в таблице БД `ng_xfields`.
- `field_XXX` — значение поля XFields с ID `XXX`.
- `flags` — массив флагов `field_XXX`; значение `TRUE` означает, что соответствующее поле заполнено.

## Пример использования

Для сайта с обзорами видеокарт можно создать такие поля:

| ID | Описание | Тип | Значения |
|---|---|---|---|
| `tested` | Проводилось тестирование | Выбор | `0 => Нет`, `1 => Да` |
| `reldate` | Дата выхода на рынок | Текст | — |
| `vendor` | Производитель | Выбор | NVidia, ATI, VIA, Intel |
| `multi` | Поддерживается установка нескольких карт | Выбор | Нет, Да |
| `index` | Индекс производительности | Текст | — |
| `result` | Мнение редакционной коллегии | Текстовый блок | — |

Пример блока в шаблоне новости:

```text
[xfield_tested]
Данный адаптер был протестирован в нашей лаборатории.<br/>
Производитель: [xvalue_vendor]<br/>
Установка нескольких адаптеров в систему: [xfield_multi]<br/>
Индекс производительности: [xfield_index]<br/>
[xfield_result]Мнение ред. коллегии:
<div>[xvalue_result]</div>
[/xfield_tested]
```

Если в поле `tested` выбрано «Да», блок будет отображаться; при выборе «Нет» — скрываться. Мнение редакционной коллегии появится, только если заполнено поле `result`.

Использование дополнительных полей сокращает предварительное форматирование новостей и помогает структурировать информацию.

## Параметры дополнительных полей

- **ID** — идентификатор поля.
- **Название** — название в форме добавления или редактирования новости.
- **Тип поля** — текст, текстовый блок или выбор значения (а также изображения, если этот тип поддерживается настройкой поля).
- **Значение по умолчанию**.
- **Список значений** — для поля типа «Выбор значения».
- **Обязательно** — для поля выбора значения определяет, обязан ли пользователь выбрать значение. Если выключено, в начало списка добавляется пустой вариант.

## Изменения ng-helpers v0.2.2

Модернизация от 31 января 2026 года добавляет безопасный доступ к массивам через `array_get()`, защиту от ошибок отсутствующих индексов, а также улучшения безопасности, логирования и производительности.
