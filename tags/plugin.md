# Облако тегов

Плагин позволяет указывать для каждой новости список тегов или ключевых слов через запятую, отображать теги в новостях, боковой панели и на отдельной странице.

Облако тегов — это визуальное представление ссылок на метки. Часто используемые или более релевантные теги могут выделяться размером.

## Возможности версии 0.30

- Совместимость с PHP 8.3.
- Обновлённые шаблоны на основе div/CSS вместо таблиц, HTML5-семантики и адаптивной вёрстки.
- Twig-синтаксис переменных `{{ variable }}`; старый синтаксис `{variable}` заменён.
- Улучшенная доступность и поддержка современных CSS3-свойств.
- Вызов облака тегов из Twig через `callPlugin()`.
- Обновление структуры базы данных при пересборке индексов.
- Автоматическое добавление названий категорий в теги с возможностью включения и отключения в настройках.

## Вывод тегов

### В новости

После активации доступны:

- Блок `[tags]...[/tags]`, который отображается, если у новости есть хотя бы один тег.
- Переменная `{{ tags }}` со списком тегов.
- Twig-переменные:
  - `p.tags.flags.haveTags` — `true`, если у новости есть теги.
  - `p.tags.value` — HTML-блок со списком тегов, аналогичный `{{ tags }}`.
  - `p.tags.count` — количество тегов новости.
  - `p.tags.list` — массив тегов; у каждого элемента доступны `name` (название), `link` (URL тега) и `value` (ссылка на тег).

Пример вывода в шаблоне новости:

```twig
{% if p.tags.flags.haveTags %}
    <div class="post-tags">
        {{ lang.tags }} ({{ p.tags.count }}):
        {% for tag in p.tags.list %}
            <a href="{{ tag.link }}" class="tag-link">{{ tag.name }}</a>{% if not loop.last %}, {% endif %}
        {% endfor %}
    </div>
{% endif %}
```

### В боковой панели

Классический способ — добавить в `main.tpl` переменную `{{ plugin_tags }}`.

Также можно вызвать облако из любого места Twig-шаблона:

```twig
{% if pluginIsActive('tags') %}
    {{ callPlugin('tags.show', {'maxnum': 12, 'counter': 1, 'template': 'sidebar', 'cacheExpire': 60}) }}
{% endif %}
```

### На странице плагина

При стандартных настройках ЧПУ страница плагина доступна по адресу `/plugin/tags/`.

## Шаблоны и параметры отображения

Для формирования переменной `{{ tags }}` используется файл `params.ini`, расположенный рядом с шаблоном плагина. В зависимости от настроек шаблон может находиться в папке плагина или в папке шаблона сайта.

### Теги в новости

Параметры в `params.ini`:

- `tag_news` — оформление тега; доступны `{{ url }}` (URL страницы тега) и `{{ tag }}` (название тега).
- `tag_news_delimiter` — разделитель тегов.

### Боковая панель

Файл `sidebar.tpl` — оболочка облака тегов в боковой панели. Доступны переменные:

- `{{ tpl_url }}` — URL шаблона сайта.
- `{{ entries }}` — список тегов.
- `{{ cloud3d }}` — вывод 3D-облака; активируется параметром конфигурации «Выводить переменную для 3D облака тегов». Пример есть в скине `3d`.

Стиль списка задаётся в `params.ini`.

### Страница облака

Файл `cloud.tpl` — оболочка облака тегов на странице плагина. Доступны:

- `{{ tpl_url }}` — URL шаблона сайта.
- `{{ entries }}` — список тегов.
- `{{ tag }}` — название отображаемого тега.
- `{{ pages }}` — блок постраничной навигации.

Стили тегов задаются в `params.ini`; стиль новостей по конкретному тегу — в `cloud.tag.entry.tpl`. Блок `[paginator]...[/paginator]` выводится, если доступна постраничная навигация.

Необязательный шаблон `cloud.tag.tpl` используется для отдельного тега. Если файла нет, используется `cloud.tpl`.

### Новости по отдельному тегу

`cloud.tag.entry.tpl` задаёт стиль отображения новостей по тегу. Доступны `{{ news_link }}` (ссылка на новость), `{{ title }}` (название) и `{{ date }}` (дата создания). Это неполный список переменных; полный список приведён в документации шаблона сайта `news.full.tpl`.

В версии 0.30 отдельный `pages.tpl` удалён: пагинация встроена в `cloud.tpl` и `sidebar.tpl` через `{{ pages }}`. Её параметры берутся из `variables.ini` текущего шаблона, секция `[navigation]`. Блоки `[prev_link]` и `[next_link]` больше не используются.

### Параметры `params.ini`

- `news.tag` — оформление тега в новости; доступны `{{ url }}` и `{{ tag }}`.
- `news.tag.delimiter` — разделитель тегов в новости.
- `news.notags` — текст, показываемый при включённой опции «Всегда выводить в новости блок с тегами».
- `sidebar.tag` — оформление тега в боковой панели; доступны `{{ url }}`, `{{ tag }}`, `{{ posts }}` (число новостей с этим тегом) и `{{ params }}` (HTML-стиль или класс).
- `sidebar.tag.delimiter` — разделитель тегов в боковой панели.
- `cloud.tag` — оформление тега на странице плагина; доступны `{{ url }}`, `{{ tag }}`, `{{ posts }}` и `{{ params }}`.
- `cloud.tag.delimiter` — разделитель тегов на странице плагина.
- `size3d.min` — минимальный размер шрифта для 3D-облака в pt (по умолчанию 10).
- `size3d.max` — максимальный размер шрифта для 3D-облака в pt (по умолчанию 18).

### Общая страница плагина

На общей странице отображается список тегов. Она использует `sidebar.tpl` вместо `cloud.tpl`; в `plugin.tpl` переменная `{{ tag }}` содержит строку «список тегов». Этот режим подходит для отображения большого списка, вплоть до нескольких сотен тегов.

### Страница конкретного тега

На странице тега показываются новости, содержащие этот тег:

- `plugin.tpl` — оболочка списка; `{{ tag }}` содержит выбранный пользователем тег.
- `entry.tpl` — строка новости; доступны `{{ news_link }}`, `{{ title }}` и `{{ date }}`.

### Форма добавления и редактирования новости

- `tags_addnews.tpl` — элементы плагина в форме добавления новости.
- `tags_editnews.tpl` — элементы плагина в форме редактирования новости.
- `{{ tags }}` — список тегов новости.

## Технические изменения версии 0.30

- Шаблоны переведены на div/CSS, HTML5-семантику и адаптивную вёрстку.
- Переменные используют Twig-синтаксис `{{ variable }}` вместо `{variable}`.
- Добавлены CSS-классы `.tags-container`, `.tags-cloud`, `.tags-list`, `.tag-item`, `.tags-form` и `.tags-navigation`.
- Добавлены совместимость с PHP 8.3, оптимизация производительности, `callPlugin()`, автообновление структуры БД при пересборке индексов и автоматическое добавление категорий в теги.

## Автоматическое добавление категорий в теги

В версии 0.30 можно автоматически добавлять названия категорий к тегам новости при сохранении.

- Функция настраивается опцией «Автоматически добавлять категории в теги» и по умолчанию отключена.
- Работает для новых и редактируемых новостей.
- Если функция включена, название категории берётся из глобального массива `$catmap` и добавляется к существующим тегам.
- Дубли не добавляются; функция работает и при отсутствии тегов, введённых вручную.

Например, для новости в категории «Технологии» с тегами `php, программирование, веб` после сохранения список станет `php, программирование, веб, Технологии`. При повторном сохранении категория не дублируется.

## Обновление с предыдущих версий

Для обновления с версии 0.25 или более ранней:

1. Загрузите новые файлы плагина.
2. Откройте настройки плагина в админке.
3. Установите параметр «Пересобрать индексы тегов» в значение «Да».
4. Сохраните настройки.

При пересборке обновляется структура таблиц для PHP 8.3, оптимизируются индексы и связи, проверяется целостность данных.

## Вызов через `callPlugin()`

Функция `callPlugin()` позволяет управлять выводом тегов из любого места Twig-шаблона:

```twig
{{ callPlugin('tags.show', параметры) }}
```

Параметры необязательны:

| Параметр | Тип и назначение | Значение по умолчанию |
|---|---|---|
| `maxnum` | Максимальное количество тегов | `20` |
| `orderby` | Сортировка: `name`, `count`, `random` | `name` |
| `orderdir` | Направление: `asc`, `desc` | `asc` |
| `template` | Имя шаблона | `sidebar` |
| `counter` | Показывать счётчик использований | `1` |
| `cache` | Использовать кеширование | `true` |
| `cacheExpire` | Время кеширования в секундах | `3600` |
| `newsfilter` | Фильтр по текущей категории: `1` — да, `0` — нет | — |

Параметр `newsfilter` работает только в контексте категорий новостей.

## Сортировка

```twig
{# В случайном порядке #}
{{ callPlugin('tags.show', {'orderby': 'random'}) }}

{# Название по возрастанию (по умолчанию) #}
{{ callPlugin('tags.show', {'orderby': 'name', 'orderdir': 'asc'}) }}
{{ callPlugin('tags.show', {}) }}

{# Название по убыванию #}
{{ callPlugin('tags.show', {'orderby': 'name', 'orderdir': 'desc'}) }}

{# Популярность по возрастанию #}
{{ callPlugin('tags.show', {'orderby': 'count', 'orderdir': 'asc'}) }}

{# Популярность по убыванию #}
{{ callPlugin('tags.show', {'orderby': 'count', 'orderdir': 'desc'}) }}
```

Соответствие значений для HTML-списка выбора:

| Значение `<option>` | Сортировка |
|---|---|
| `0` | `orderby: random` |
| `1` | `orderby: name`, `orderdir: asc` |
| `2` | `orderby: name`, `orderdir: desc` |
| `3` | `orderby: count`, `orderdir: asc` |
| `4` | `orderby: count`, `orderdir: desc` |

## Примеры использования

```twig
{# Простое облако тегов #}
{{ callPlugin('tags.show') }}

{# Топ-10 популярных тегов #}
{{ callPlugin('tags.show', {'maxnum': 10, 'orderby': 'count', 'orderdir': 'desc'}) }}

{# Случайные теги с кешированием на 5 минут #}
{{ callPlugin('tags.show', {'maxnum': 15, 'orderby': 'random', 'cacheExpire': 300}) }}

{# Пользовательский шаблон облака #}
{{ callPlugin('tags.show', {'template': 'cloud', 'maxnum': 25}) }}

{# Теги по алфавиту без счётчиков #}
{{ callPlugin('tags.show', {'orderby': 'name', 'orderdir': 'asc', 'counter': 0}) }}

{# Популярные теги с кешированием на 2 часа #}
{{ callPlugin('tags.show', {'maxnum': 20, 'orderby': 'count', 'orderdir': 'desc', 'cacheExpire': 7200}) }}
```

## Рекомендуемые конфигурации

Боковая панель с популярными тегами:

```twig
{{ callPlugin('tags.show', {
    'maxnum': 15,
    'template': 'sidebar',
    'orderby': 'count',
    'orderdir': 'desc',
    'counter': 1,
    'cacheExpire': 1800
}) }}
```

Страница облака тегов — алфавитный порядок:

```twig
{{ callPlugin('tags.show', {
    'template': 'cloud',
    'orderby': 'name',
    'orderdir': 'asc',
    'counter': 1
}) }}
```

Случайная подборка:

```twig
{{ callPlugin('tags.show', {
    'maxnum': 10,
    'template': 'sidebar',
    'orderby': 'random',
    'counter': 0,
    'cacheExpire': 300
}) }}
```

Компактный список без счётчиков:

```twig
{{ callPlugin('tags.show', {
    'maxnum': 30,
    'template': 'sidebar',
    'orderby': 'name',
    'counter': 0
}) }}
```

## Использование с условиями

Проверка активности плагина:

```twig
{% if pluginIsActive('tags') %}
    {{ callPlugin('tags.show', {'maxnum': 12, 'orderby': 'count', 'orderdir': 'desc'}) }}
{% endif %}
```

Разные параметры для разных страниц:

```twig
{% if isHandler('news:main') %}
    {{ callPlugin('tags.show', {'maxnum': 10, 'orderby': 'random'}) }}
{% else %}
    {{ callPlugin('tags.show', {'maxnum': 15, 'orderby': 'count', 'orderdir': 'desc'}) }}
{% endif %}
```

## Примечания

- Все параметры `callPlugin()` необязательны.
- Кеширование снижает нагрузку на базу данных; вызовы с разными параметрами кешируются независимо.
- Для тегов внутри новости используйте `p.tags.*`, а не `callPlugin()`.
