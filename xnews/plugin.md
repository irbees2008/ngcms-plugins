# Блоки новостей

Плагин выводит на сайте информационные блоки по заданным критериям и функционально заменяет `lastnews` и `top_news`.

## Шаблоны и их расположение

Плагин использует два Twig-шаблона: `entries.tpl` и `xnews.tpl`. Для каждого профиля указывается каталог шаблонов.

Порядок поиска:

1. `templates/ВАШ_ШАБЛОН/plugins/xnews/КАТАЛОГ/` — проверяются `entries.tpl` и `xnews.tpl`.
2. Если файлы не найдены, проверяется `engine/plugins/xnews/tpl/КАТАЛОГ/`.
3. Если шаблоны не найдены, выводится сообщение об ошибке.

Если каталог не задан, плагин пытается использовать `engine/plugins/xnews/tpl/example/`.

### `entries.tpl`

Шаблон данных одной новости. Поддерживает возможности `news.short.tpl` и дополнительные переменные Twig:

- `news.author.name` — имя автора.
- `news.author.url` — ссылка на профиль автора.
- `news.author.id` — ID автора.
- `news.title` — заголовок.
- `news.short` — короткая новость.
- `news.full` — полная новость.
- `news.categories.masterText` — HTML-ссылка на главную категорию.
- `news.categories.text` — HTML-список категорий со ссылками.
- `news.categories.count` — количество категорий новости.
- `news.categories.list` — список категорий; у каждой доступны:
  - `id` — ID категории.
  - `alt` — альтернативное имя.
  - `name` — название.
  - `icon` — иконка.
  - `url` — URL категории.
  - `text` — HTML-ссылка на категорию.
- `news.url.full` — ссылка на новость.
- `news.url.print` — ссылка на версию для печати.
- `news.flags.isUpdated` — признак редактирования новости.
- `news.update` — дата и время обновления в стандартном формате.
- `news.updateStamp` — время обновления в UNIX timestamp.
- `news.date` — дата и время публикации в стандартном формате.
- `news.dateStamp` — дата и время публикации в UNIX timestamp.
- `news.views` — число просмотров.
- `news.flags.canEdit` — может ли посетитель редактировать новость.
- `news.flags.canDelete` — может ли посетитель удалить новость.
- `news.url.edit` — URL редактирования.
- `news.url.delete` — URL удаления.
- `_files` — приложенные файлы.
- `_images` — приложенные изображения.

Если включена опция `extractEmbeddedItems` («Извлекать URL изображений из текста новости»), дополнительно доступны:

- `news.embed.imgCount` — количество извлечённых изображений.
- `news.embed.images` — список URL изображений.

### `xnews.tpl`

Основной шаблон блока:

- `entriesCount` — количество найденных новостей.
- `entries` — массив отрендеренных шаблонов `entries.tpl`.

## Вызов блока из Twig

Данные плагина выводятся через Twig-функцию `callPlugin('xnews.show', параметры)`.

### Параметры `xnews.show`

- `id` — ID блока из настроек плагина. При указании используются настройки этого блока.
- `categoryMode` — выбор категорий:
  - `0` — только категории из `categories`.
  - `1` — только текущая категория.
  - `2` — категории из `categories` и текущая категория.
- `categories` — список ID категорий через запятую.
- `visibilityMode` — область видимости:
  - `0` — везде.
  - `1` — страницы категорий.
  - `2` — страницы новостей.
  - `3` — страницы категорий и новостей.
- `visibilityCList` — список ID категорий через запятую; применяется, если `visibilityMode > 0`.
- `mainMode` — фильтр новостей с главной:
  - `0` — все новости.
  - `1` — только новости с главной.
  - `2` — только новости не с главной.
- `pinMode` — фильтр закреплённых новостей:
  - `0` — все новости.
  - `1` — только закреплённые.
  - `2` — только незакреплённые.
- `favMode` — фильтр закладок администратора:
  - `0` — все новости.
  - `1` — только новости из закладок администратора.
  - `2` — только новости не из закладок администратора.
- `count` — количество новостей.
- `skip` — порядковый номер новости, с которой начинать вывод.
- `maxAge` — ограничение по давности публикации в днях.
- `order` — порядок вывода: `viewed` (по просмотрам, убывание), `commented` (по комментариям, убывание), `random` (случайный), `last` (по дате публикации), `editdate` (по дате редактирования).
- `showNoNews` — показывать ли блок, если новостей нет (`true`/`false`).
- `skipCurrent` — не показывать текущую новость. При этом режиме кеширование новостей недоступно.
- `cacheAge` — срок кеширования блока в секундах, если значение больше `0`.
- `template` — каталог шаблона, содержащий `entries.tpl` и `xnews.tpl`. Обязателен, если блок не вызывается по ID из настроек.

### Примеры вызова

Блок с ID `main`:

```twig
{{ callPlugin('xnews.show', {'id': 'main'}) }}
```

Новости категории с ID `15`:

```twig
{{ callPlugin('xnews.show', {'categoryMode': 0, 'categories': '15', 'template': 'xnews1'}) }}
```

## Примеры шаблонов

Пример `entries.tpl`:

```twig
<li>
  <a href="{{ link }}">
    {% if title|length > 15 %}{{ title|slice(0, 15) }}..{% else %}{{ title }}{% endif %}<br/>
    {{ dateStamp|date("m/d/Y G:i") }}
  </a>
  {% if pluginIsActive('uprofile') %}<a href="{{ author_link }}">{{ author_name }}</a>{% endif %}
  {{ category }}
  {% if flags.canEditNews %}<img src="{{ skins_url }}/images/rewrite.gif">{% endif %}<br/>
</li>
<br/>
```

В примере заголовок обрезается до 15 символов, дата форматируется из `dateStamp`, ссылка на автора показывается при активном `uprofile`, а изображение `rewrite.gif` выводится, если посетитель может редактировать новость.

Пример `xnews.tpl`:

```twig
<div>
  <ul>
    {% for entry in entries %}
      {{ entry }}
    {% endfor %}
  </ul>
</div>
```

Этот шаблон выводит все найденные новости.
