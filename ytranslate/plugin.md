# YTranslate

Переключатель языков для NGCMS с единым серверным слоем перевода. Плагин переводит текстовые узлы страницы в браузере, а обращения к API выполняются сервером, поэтому ключи провайдеров не попадают посетителям.

## Провайдеры

Поддерживаются Yandex Cloud Translate, Google Cloud Translation, Microsoft Translator, LibreTranslate и DeepL. В настройках задаётся основной провайдер и до четырёх резервных. Если основной сервис не настроен, отвечает ошибкой или недоступен, плагин последовательно пробует резервные.

Для каждого выбранного сервиса нужен соответствующий ключ. Для LibreTranslate по умолчанию используется центральный сервер `https://translate.ngcms.org`; его ключ передаётся только сервером сайта в JSON-запросе. URL можно заменить на свой совместимый экземпляр, Microsoft иногда требует регион, а для DeepL нужно указать, используется ли Free endpoint.

Переводы LibreTranslate кэшируются по провайдеру, языкам и SHA-256 текста на 30 дней. Для незакэшированных текстов плагин пытается использовать batch-запрос, а при неподдержанном формате ответа автоматически переходит к отдельным запросам с сохранением порядка.

## Языки

Доступны 10 языков: русский, украинский, белорусский, казахский, узбекский, кыргызский, таджикский, английский, немецкий и китайский. Они включаются чекбоксами в настройках. Русский включён по умолчанию как исходный язык сайта.

## Определение по IP

Опция «Предлагать язык по IP страны» включает автоматический выбор языка. Сначала используются заголовки `CF-IPCountry` или `X-Country`, затем для публичного IP применяется `ipapi.co`. Результат сохраняется в `localStorage`; ручной выбор пользователя имеет приоритет.

## Установка

1. Скопируйте каталог `engine/plugins/ytranslate` в NGCMS.
2. Включите плагин в панели администратора.
3. Откройте настройки. Для центрального LibreTranslate нажмите «Получить ключ»; выданный ключ сохраняется отдельно в настройках плагина. Существующее ручное поле `libre_key` автоматически не заменяется.
4. Укажите провайдеров и языки, затем добавьте в шаблон:

```twig
{{ callPlugin('ytranslate.show', {
    position: 'fixed',
    theme: 'light'
}) }}
```

`position: 'fixed'` закрепляет переключатель в правом верхнем углу. Для обычного размещения используйте `position: 'static'`.

## Требования и безопасность

- PHP 7.2+ с HTTPS-доступом к API провайдеров;
- для центрального LibreTranslate нужен выданный сервером API-ключ;
- для перевода требуется хотя бы один доступный и настроенный API-провайдер;
- запросы к переводчикам выполняются только сервером;
- переведённый текст не сохраняется в базе данных;
- поля ввода, код, скрипты и сам переключатель исключены из перевода.
