# AI Rewriter

Плагин выполняет рерайт текста новости прямо в форме добавления или редактирования.
Версия `0.1.2` включает интеграцию с ng-helpers `0.2.2` для защиты и логирования.

## Возможности

- Переписывает текст через кнопку в панели инструментов редактора.
- Поддерживает OpenAI, Anthropic и OpenAI-совместимые API.
- Позволяет настраивать провайдера, API-ключ, модель, оригинальность, тональность,
  температуру и таймаут.
- Поддерживает автоматический рерайт при сохранении новости.
- Защищает административные функции и RPC-вызовы от CSRF.
- Ведёт журнал операций с уровнями `info`, `warning` и `error`.

Рерайт по кнопке заменяет текст в поле редактора, но не сохраняет новость. Результат
следует проверить и сохранить обычной кнопкой.

## Требования

- NGCMS `0.9.3` или новее.
- PHP `7.0` или новее.
- ng-helpers `0.2.2` или новее для CSRF-защиты.
- Включённое расширение cURL.

## Установка

1. В админ-панели откройте **Плагины → ai_rewriter → Установить**.
2. Откройте настройки плагина.
3. Выберите провайдера и укажите параметры API и модели.

## Настройки

### Провайдер

- **OpenAI** — официальный API OpenAI.
- **Совместимый (кастомный API Base)** — OpenAI-совместимые API и прокси, например
  OpenRouter, Together, LM Studio или Ollama.
- **Anthropic (Claude)** — официальный API Anthropic.

### Модель

- Для OpenAI укажите доступную модель, например `gpt-4o-mini` или `gpt-4.1`.
- Для совместимого API укажите точный идентификатор модели у выбранного провайдера.
- Для Anthropic используйте модель семейства `claude-*`, например
  `claude-3-5-sonnet-20240620` или `claude-3-haiku-20240307`.

### API Key

Укажите ключ доступа к выбранному провайдеру:

- OpenAI — [получить API-ключ](https://platform.openai.com/api-keys).
- Anthropic — [получить API-ключ](https://console.anthropic.com/settings/keys).
- OpenRouter — [получить API-ключ](https://openrouter.ai/keys).
- Together — [получить API-ключ](https://api.together.xyz/settings/keys).
- Для локальных LM Studio и Ollama ключ обычно не требуется.

### API Base

Необязательный базовый URL для совместимого API или прокси:

| Провайдер | API Base |
| --- | --- |
| OpenAI | `https://api.openai.com/v1` (можно оставить поле пустым) |
| OpenRouter | `https://openrouter.ai/api/v1` |
| Together | `https://api.together.xyz/v1` |
| LM Studio | `http://127.0.0.1:1234/v1` |
| Ollama | `http://127.0.0.1:11434/v1` |

### Остальные параметры

- **Процент оригинальности** — целевая уникальность текста от `0` до `100`; по
  умолчанию `60`.
- **Тональность** — необязательное описание стиля, например «нейтральный» или
  «информационный».
- **Temperature** — степень вариативности ответа от `0.0` до `1.0`; по умолчанию
  `0.7`.
- **Таймаут запроса** — максимальное время ожидания ответа API в секундах; по
  умолчанию `20`. При медленном соединении можно увеличить до `45–60`.
- **Автоприменение** — запускать рерайт при добавлении или редактировании новости.
  По умолчанию выключено.

## Использование

1. В админ-панели откройте **Новости → Добавить** или **Новости → Редактировать**.
2. В панели инструментов редактора нажмите кнопку с иконкой волшебной палочки.
3. Дождитесь ответа: плагин отправит текущий текст в ИИ и заменит текст в поле.
4. Проверьте результат, при необходимости отредактируйте его и сохраните новость.

Нажатие кнопки не отправляет форму и не сохраняет новость.

## Сохранение разметки

Плагин инструктирует ИИ сохранять HTML и BBCode, структуру, абзацы, заголовки,
ссылки и специальные символы. ИИ не должен добавлять факты или менять смысл текста.
Перед публикацией обязательно проверьте результат.

## Примеры конфигурации

### OpenAI

- Провайдер: **OpenAI**.
- API Base: пустое поле или `https://api.openai.com/v1`.
- API Key: ваш ключ OpenAI.
- Модель: `gpt-4o-mini`.

### OpenRouter

- Провайдер: **Совместимый (кастомный API Base)**.
- API Base: `https://openrouter.ai/api/v1`.
- API Key: ваш ключ OpenRouter.
- Модель: точный идентификатор модели в каталоге OpenRouter.

### Ollama

- Провайдер: **Совместимый (кастомный API Base)**.
- API Base: `http://127.0.0.1:11434/v1`.
- API Key: не требуется.
- Модель: имя запущенной модели, например `llama3` или `mistral`.

## Типовые ошибки

- **`You exceeded your current quota`** — закончилась квота или не настроена оплата.
  Пополните баланс или выберите другого провайдера.
- **`AI ключ не задан`** — заполните поле API Key в настройках.
- **Провайдер и модель не совпадают** — выберите модель, совместимую с провайдером.
  Например, для Anthropic указывайте модель `claude-*`, а не `gpt-*`.
- **`cURL error: Operation timed out`** — проверьте сеть и настройки прокси; при
  необходимости увеличьте таймаут до `45–60` секунд.

## Часто задаваемые вопросы

**Можно выполнить рерайт без сохранения новости?**  
Да. Кнопка меняет текст в поле редактора, но не отправляет форму.

**Можно включить автоматический рерайт при сохранении?**  
Да. В настройках есть отдельные параметры для добавления и редактирования новости.

**Где посмотреть ошибки?**  
Ошибки отображаются в уведомлениях. Дополнительную диагностику можно искать в логах
PHP и веб-сервера.

## Технические сведения

- Кнопка редактора вызывает RPC-метод `ai_rewriter.rewrite` через `engine/rpc.php`.
- `ai_rewriter.php` — провайдеры, логика рерайта, хуки NewsFilter и RPC.
- `lib/librpc.php` — загрузчик RPC для движка.
- `config.php` — настройки плагина и их защита от CSRF.
- `install.php` — установка и значения по умолчанию.
- Кнопка добавлена в `engine/skins/default/tpl/qt_news.tpl`.

## Безопасность и логирование

Функции версии `0.1.2` включают:

- проверку авторизации администратора для RPC;
- защиту административных функций встроенными средствами NGCMS;
- валидацию URL API перед запросом (`validate_url`);
- очистку пользовательских данных (`sanitize`);
- логирование операций.

Файл журнала: `engine/logs/ai_rewriter.log`.

Уровни журнала:

- `INFO` — успешные операции и информационные сообщения;
- `WARNING` — ошибки CSRF и некритичные проблемы;
- `ERROR` — ошибки API, таймауты и недоступность провайдера.

Пример записей:

```text
[2025-01-15 14:32:11] [INFO] RPC rewrite request: length=1250 chars
[2025-01-15 14:33:05] [WARNING] RPC error: CSRF validation failed
[2025-01-15 14:35:22] [ERROR] RPC error: OpenAI API error: 429 Too Many Requests
```
