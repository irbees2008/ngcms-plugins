# Новости пользователя

Плагин выводит на отдельной странице ленту новостей пользователя.

## Интеграция с профилем uprofile

На странице просмотра профиля пользователя плагин:

- Может подменять значение переменной `{news}`.
- Создаёт Twig-переменную `p.ublog.flags.haveBlog`, которая принимает `TRUE`, если у пользователя есть опубликованные новости.
- Создаёт Twig-переменную `p.ublog.blogLink` — URL ленты новостей пользователя, если она доступна.

Плагин также поддерживает собственный шаблон `ublog.tpl`, в котором можно показывать сведения об авторе, включая дополнительные поля (аналогично информации плагина `uprofile`).

## Переменные шаблона `ublog.tpl`

- `user` — массив с данными пользователя из таблицы `users`:
  - `id` — ID пользователя.
  - `name` — логин.
  - `news` — количество новостей пользователя.
  - `com` — количество комментариев пользователя.
  - `status` — название группы пользователя.
  - `last` — дата и время последнего посещения.
  - `reg` — дата и время регистрации.
  - `from` — поле «Откуда».
  - `info` — поле «Информация обо мне».
  - `flags` — массив признаков пользователя:
    - `hasAvatar` — флаг наличия аватара.
- `news` — найденные новости:
  - `count` — количество новостей, отображаемых на странице.
  - `entries` — массив отрендеренных новостей.
- `pages` — данные постраничной навигации:
  - `current` — номер текущей страницы.
  - `total` — общее количество страниц.
  - `output` — отрендеренная постраничная навигация.
