# Новости по расписанию

Плагин позволяет задать дату и время публикации и снятия с публикации каждой новости. После активации в форме добавления и редактирования новостей появляются дополнительные поля. Плагин также синхронизирует даты создания, редактирования и публикации новости.

## Известные проблемы при установке

### Ошибка `datetime`

На системах с MySQL 5.7 и новее может появиться ошибка:

```text
SQLSTATE[22007]: Invalid datetime format: 1292 Incorrect datetime value:
'0000-00-00 00:00:00' for column 'nsched_activate/nsched_deactivate'
```

### Ошибка `Column not found`

При установке также может появиться ошибка:

```text
SQLSTATE[42S22]: Column not found: 1054 Unknown column 'nsched_activate'
in 'where clause'
```

### Решение

Автоматическая проверка наличия полей перед очисткой встроена в `install.php` версии 2.0 и рассчитана на новые и существующие установки.

Если требуется ручное исправление, выполните SQL-скрипт `fix_datetime_issue.sql` из папки плагина. Приведённые ниже команды иллюстрируют добавление полей и очистку проблемных значений:

```sql
ALTER TABLE `ng_news` ADD COLUMN IF NOT EXISTS `nsched_activate` INT(10) NOT NULL DEFAULT 0;
ALTER TABLE `ng_news` ADD COLUMN IF NOT EXISTS `nsched_deactivate` INT(10) NOT NULL DEFAULT 0;
UPDATE `ng_news` SET `nsched_activate` = 0 WHERE `nsched_activate` IN ('0000-00-00 00:00:00', '0');
ALTER TABLE `ng_news` MODIFY COLUMN `nsched_activate` INT(10) NOT NULL DEFAULT 0;
```

Причины проблем:

- Старые версии MySQL допускали недопустимое значение `0000-00-00 00:00:00`.
- При первой установке могла выполняться очистка несуществующих полей.
- При обновлении с предыдущих версий возможны конфликты типов данных.

## Установка

1. Загрузите архив плагина в `/engine/plugins/` и распакуйте его (должна появиться папка `nsched`).
2. В админ-панели откройте «Система» → «Управление плагинами».
3. Найдите NSched, нажмите «Установить», затем «Включить».
4. При необходимости откройте «Плагины» → «NSched» → «Настройки».
5. В системных настройках выберите часовой пояс сайта: «Настройки системы» → «Основные настройки» → «Временная зона».

## Использование

В форме добавления или редактирования новости появится блок «Управление публикацией новостей».

- **Активация:** задайте дату включения в формате `ДД.ММ.ГГГГ ЧЧ:ММ`. Чтобы отложенная публикация сработала, сохраните новость на модерацию.
- **Деактивация:** задайте дату отключения. Для этого требуются права `unpublish`; если планируется только снятие с публикации, новость должна быть опубликована.
- Используйте встроенный datetimepicker для выбора даты и времени.

Важные особенности:

- Дата деактивации не может быть раньше даты активации.
- Если дата не задана, соответствующее действие не выполняется.
- При сохранении даты преобразуются в UNIX timestamp.
- При создании или редактировании новости даты прошедшего времени автоматически сбрасываются.

## CRON-обработчик

Для автоматической публикации и деактивации настройте CRON-задачу, запускаемую каждые 5–10 минут.

## Безопасность

- Даты проверяются с помощью `DateTime::createFromFormat()`.
- SQL-запросы используют встроенную защиту от инъекций.
- Перед сохранением обязательно проверяются права доступа.

## Примеры использования

- **Отложенные публикации:** подготовьте новости заранее и укажите дату их активации, например на время отпуска администратора.
- **Новости с ограниченным сроком актуальности:** задайте дату автоматического снятия с публикации вместо удаления старой новости.
- **Рекламные материалы:** укажите срок размещения новости в соответствии с оплаченным периодом.
