# Сообщение о проблеме в новости

Версия документации: `0.08` (30.01.2026).

Плагин `complain` добавляет обратную связь: посетитель может сообщить о проблеме,
обнаруженной в новости. Он особенно полезен на сайтах со ссылками на внешние ресурсы.

**Требования:** NGCMS 0.9.2+, PHP 7.0+, ng-helpers v0.2.2+.

## Технические улучшения v0.08

- Плагин использует ng-helpers v0.2.2.
- Для чтения входных данных используется `array_get()` вместо прямого доступа к `$_REQUEST`.
- Операции записываются в `complain.log`; для аудита также используются `logger()` и `get_ip()`.
- Входные данные очищаются и проверяются функциями `sanitize()` и `validate_email()`.
- Устранены PHP Notice вида `Undefined index`.

В журнал записываются создание жалоб, изменение их статуса и владельца, отправка
уведомлений по email, сохранение настроек и попытки отправки некорректных данных.

## Настройка плагина

Сначала задайте список типов ошибок, которые пользователь сможет выбрать:

```text
1|Неверная ссылка
2|Ссылка удалена
3|Другая ошибка
```

Затем укажите, кого и каким способом уведомлять о жалобах, а также разрешено ли
отправлять отчёты незарегистрированным пользователям.

## Подключение шаблонов

Кнопка или ссылка с классом `complain-open` доступна на страницах сайта и открывает
модальное окно через AJAX. В шаблоне полной новости можно вывести блок плагина:

```twig
{% if pluginIsActive('complain') %}
    {{ plugin_complain }}
{% endif %}
```

Ссылка на админский список жалоб доступна из пользовательского меню
(см. `templates/*/usermenu.tpl`). Пример ссылки:

```twig
<a href="{{ p.complain.link|default(home ~ '/plugin/complain/?ajax=1') }}" class="complain-open" data-modal="true">
    Жалобы ({{ p.complain.new_count|default(0) }})
</a>
```

Счётчик «Жалобы (N)» обновляется автоматически, в том числе после действий в модальном окне.
