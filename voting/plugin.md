# Опросы

Плагин позволяет проводить опросы посетителей сайта.

## Возможности

- Одновременное проведение нескольких опросов.
- Просмотр всех активных опросов на странице плагина:
  - ЧПУ: `/plugin/voting/`.
  - Без ЧПУ: `/?action=plugin&plugin=voting`.
- Режим отображения: всегда показывать выбранный опрос или ротировать активные опросы.
- Для каждого опроса можно задать флаги:
  - **Активен** — опрос виден посетителям, голосование доступно.
  - **Закрыт** — опрос виден, но голосование недоступно.
  - **Только для зарегистрированных** — голосовать могут только зарегистрированные пользователи.
- Защита от повторного голосования:
  - **Cookie** — информация о голосе хранится в cookie; низкий уровень защиты.
  - **База данных** — информация о голосовании зарегистрированных пользователей хранится в БД; защита выше, но выполняются дополнительные SQL-запросы.
- Несколько скинов, переключаемых в админ-панели плагина.
- Ручная настройка счётчиков для вариантов ответа.
- Изменение параметров уже опубликованного опроса.
- Деактивация вариантов ответа. Неактивные варианты недоступны посетителям, но видны в панели управления.

> Шаблон, поставляемый по умолчанию, работает только в режиме ЧПУ.

## Скины и шаблоны

Скины находятся в `engine/extras/voting/tpl/skins/`; каждый каталог соответствует скину.

### `lshdr.tpl`

Заголовочный файл с JavaScript для AJAX-запросов. Функция `make_voteL(mode, vid)` обрабатывает нажатия кнопок «Голосовать» и «Результаты». Используется только на странице плагина со списком опросов.

- `{home}` — URL сайта.

### Список опросов на странице плагина

#### `shls_vote.tpl`

Заголовок опроса в режиме просмотра:

- `{voteid}` — ID опроса.
- `{votename}` — название.
- `{votedescr}` — описание.
- `{votelines}` — строки опроса, сформированные через `shls_vline.tpl`.
- `{home}` — URL сайта.
- `{tpl_dir}` — URL шаблона.
- `{vcount}` — общее количество участников.
- Блок `[votedescr]...[/votedescr]` выводится, если у опроса есть описание.

#### `shls_vline.tpl`

Строка опроса в режиме просмотра:

- `{id}` — ID строки.
- `{name}` — название или текст строки.
- `{num}` — порядковый номер строки; может использоваться для чередования оформления шкал.
- `{count}` — количество голосов за вариант.
- `{perc}` — процент голосов числом; может использоваться для ширины графической шкалы.
- `{tpl_dir}` — URL шаблона.

#### `edls_vote.tpl` и `edls_vline.tpl`

Заголовок и строка опроса в режиме голосования. Переменные аналогичны `shls_vote.tpl` и `shls_vline.tpl` соответственно.

### Активный опрос на главной странице

- `ls_vote.tpl` — заголовок опроса в режиме просмотра; переменные как в `shls_vote.tpl`.
- `ls_vline.tpl` — строка опроса в режиме просмотра; переменные как в `shls_vline.tpl`.
- `ed_vote.tpl` — заголовок опроса в режиме голосования; переменные как в `shls_vote.tpl`.
- `ed_vline.tpl` — строка опроса в режиме голосования; переменные как в `shls_vline.tpl`.

Если скин должен поддерживать AJAX, `ed_vline.tpl` также должен содержать код для генерации AJAX-запроса.
