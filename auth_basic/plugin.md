# Базовый модуль авторизации

Плагин обеспечивает базовые возможности авторизации пользователей на сайте и
является обязательным.

## Возможности

- Авторизация пользователя по логину и паролю с сохранением уникального ID сессии
  в cookie.
- Получение данных пользователя по ID сессии и инициализация глобального массива
  `$userROW` с информацией о пользователе.
- Восстановление забытого пароля.
- Регистрация пользователей с одним из следующих способов:
  - **Мгновенная регистрация:** пользователь вводит логин, пароль и email; учётная
    запись активируется сразу.
  - **Простая регистрация:** пользователь вводит логин и email, а пароль получает
    по электронной почте.
  - **Регистрация с подтверждением:** пользователь вводит логин, пароль и email;
    учётная запись активируется после перехода по специальной ссылке из письма.

## Общий префикс таблицы пользователей

Плагин позволяет задавать собственный префикс для таблицы с пользователями.
Это позволяет использовать единую учётную запись на нескольких сайтах, если они
работают с одной базой данных.
