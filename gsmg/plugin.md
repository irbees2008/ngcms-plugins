# Генератор карты сайта GSMG

GSMG создаёт XML-карту сайта для поисковых систем на основе новостей, категорий и
статических страниц NGCMS.

## Адреса

- Карта сайта: `https://ваш-сайт.ru/gsmg.xml`
- Страница плагина: `https://ваш-сайт.ru/plugin/gsmg/`

Замените `https://ваш-сайт.ru` на адрес своего сайта. Маршруты регистрируются при
установке плагина. Если после обновления файлов карта недоступна, повторно примените
установку GSMG, чтобы обновить правила ЧПУ.

Для добавления карты в `robots.txt` используйте директиву:

```text
Sitemap: https://ваш-сайт.ru/gsmg.xml
```

## Настройка

Параметры доступны в разделе управления плагинами NGCMS.

| Раздел | Параметры |
| --- | --- |
| Главная страница | Добавление главной страницы и её пагинации; приоритет каждой записи |
| Категории | Добавление страниц категорий и их пагинации; приоритет каждой записи |
| Новости | Добавление страниц опубликованных новостей и их приоритет |
| Статические страницы | Добавление статических страниц и их приоритет |
| Кеширование | Включение кеша и срок его действия в секундах |

Приоритет задаётся числом от `0.0` до `1.0`. Значение срока кеширования по умолчанию —
`10800` секунд (3 часа).

## Формат и содержимое карты

`/gsmg.xml` отдаёт XML-индекс карты сайта. Адреса отдельных XML-файлов перечисляются
внутри индекса. Файлы создаются в корневом каталоге сайта; каждая часть содержит не
более 50 000 URL.

В карту могут входить:

- главная страница и, если включено, её пагинация;
- страницы категорий и, если включено, их пагинация;
- опубликованные новости;
- опубликованные статические страницы;
- дополнительные записи, добавленные другими плагинами через фильтр GSMG.

Для главной страницы и категорий указывается дата последнего добавления новости.
Для статических страниц также используется дата последнего добавления новости.
Для каждой новости указывается более поздняя из даты публикации и даты редактирования.

Для главной страницы, категорий и новостей используется частота `daily`; для
статических страниц — `weekly`.

## Кеширование и мультисайт

При включённом кешировании индекс карты хранится в кеше в течение заданного периода.
После истечения срока карта будет сформирована заново.

В режиме мультисайта карта формируется для текущего сайта. Для отдельных доменов
используются отдельные имена кеша и XML-файлов, чтобы карты сайтов не пересекались.
