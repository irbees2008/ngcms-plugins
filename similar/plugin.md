# Похожие новости

Плагин автоматически перелинковывает новости, используя данные плагина «Теги». При добавлении или редактировании новости он проверяет её теги и находит публикации с похожим набором тегов. Найденные новости можно выводить на странице полной новости в блоке «Похожие новости».

## Настройки

- **Восстановление индексов** — запускайте, если блок похожих новостей отображается неверно, а также после обновления плагина.
- **Шаблон для отображения** — выберите источник шаблонов. Если выбран шаблон сайта, файлы ищутся в `templates/<ваш шаблон>/plugins/similar/`.
- **Количество новостей в блоке** — число наиболее похожих публикаций. По умолчанию — 5, максимум — 20. После изменения значения необходимо восстановить индексы.

## Шаблоны

### `similar.tpl`

Основной шаблон блока. Переменная `{{ entries }}` содержит отрендеренные строки. Поддерживается также устаревшая переменная `{entries}`.

### `similar_entry.tpl`

Шаблон строки блока. Современные Twig-переменные:

- `{{ news.date }}` — дата создания новости в готовом виде.
- `{{ news.url.full }}` — полная ссылка на новость.
- `{{ news.title }}` — название новости.
- `{{ news.author.name }}` — имя автора.
- `{{ news.short }}` — краткое содержание.
- `{{ news.categories.masterText }}` — основная категория.
- `{{ news.embed.images[0] }}` — первое встроенное изображение.
- `{{ news.embed.imgCount }}` — количество изображений.
- `{{ tpl_url }}` — URL ресурсов шаблона.

Устаревшие переменные, которые пока поддерживаются:

- `{date}` — дата создания новости.
- `{url}` — URL новости.
- `{title}` — название новости.

## Обновление до версии 0.08

Версия 0.08 (2026-05-26) добавляет поддержку Twig и объекта `news.*`, кеширование похожих новостей на 5 минут, автоматическое использование `newsFillVariables()`, поддержку PHP 8.1+ и оптимизированный рендеринг шаблонов.

После обновления:

1. Обновите `similar.tpl` и `similar_entry.tpl`, используя современный синтаксис.
2. Замените `{date}`, `{url}` и `{title}` на `{{ news.date }}`, `{{ news.url.full }}` и `{{ news.title }}`.
3. Запустите «Восстановление индексов» в админ-панели плагина.
4. Очистите кеш плагина, удалив файлы из `engine/cache/similar/`.

## Требования и кеширование

- Для отображения похожих новостей у публикаций должны быть теги.
- Плагин автоматически использует `newsFillVariables()` для создания полного объекта `news` с поддержкой современных переменных и функций.
- Результаты кешируются на 5 минут для снижения нагрузки на базу данных.
