# Переключатель языков и шаблонов (`switcher`)

Сервисный плагин `switcher` позволяет использовать разные языковые файлы и шаблоны. Посетитель может выбрать язык или скин в меню; также один и тот же сайт можно настроить на нескольких доменах с разными профилями оформления.

## Профили

Каждый профиль содержит следующие параметры:

- **Активен** — признак активности профиля.
- **Шаблон** — шаблон, который будет отображаться при активации профиля.
- **Язык** — языковой пакет для профиля.
- **Наименование** — название профиля в списке выбора.
- **Идентификатор** — позволяет сформировать ссылку для активации профиля с внешнего сайта при включённой опции «собственная страница переадресации». Идентификатор активного профиля должен состоять только из латинских букв и цифр.
- **По умолчанию для доменов** — список доменов, на которых профиль активируется по умолчанию. Используется в режиме мультидоменности.

Ссылки для активации профиля:

- ЧПУ: `/plugin/switcher/?profile=<ID>`.
- Без ЧПУ: `?action=plugin&plugin=switcher&profile=<ID>`.

Пример для профиля с ID `en`: `/plugin/switcher/?profile=en`.

## Cookies

Активный профиль сохраняется в cookie `sw_template`. Если cookies отключены в браузере пользователя, плагин работает только в случае, когда профили размещены на разных доменных именах.

## Меню выбора

Добавьте в `main.tpl` переменную `{switcher}` — на её месте появится меню выбора. Меню формируется шаблоном `tpl/switcher.tpl`; его можно менять, сохраняя работу с cookies.

## Профили на разных доменах

Чтобы автоматически показывать разные профили на разных доменах без выбора посетителя:

1. В настройках системы укажите домены в разделе «Настройки» → «Настройки системы» → «Домены» → «Список доменных имён сайта». Это активирует мультидоменность.
2. Настройте систему для работы в мультидоменном режиме.
3. В профилях `switcher` укажите соответствующие домены в поле «По умолчанию для доменов».
