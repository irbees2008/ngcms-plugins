# Формы обратной связи

## Модернизация с ng-helpers v0.2.2

Обновление от 31 января 2026 года:

- `array_get()` обеспечивает безопасный доступ к `$_REQUEST` и `$_POST`
  (более 50 замен).
- `logger(message, level, file)` используется для структурированного логирования.
- CSRF-защита выполняется через `validate_csrf()` и `csrf_field()`.
- Адреса электронной почты проверяются через `validate_email()`.
- Входные данные очищаются через `sanitize()`.
- Добавлена защита от предупреждений `Undefined index`.
- Повышены безопасность и стабильность плагина.

## О плагине

Плагин `feedback` позволяет администратору создавать формы обратной связи,
которые заполняют посетители.

Плагином поддерживается неограниченное кол-во форм, внутри формы может быть
любое кол-во полей.
Поля формы могут иметь следующие типы:

1. **Текстовое поле** — одна строка.
2. **Текстовый блок** — многострочное поле (`textarea`).
3. **Поле выбора** — выпадающий список с вариантами, заданными администратором.
4. **Дата** — три выпадающих списка для выбора дня, месяца и года.
5. **Email** — поле адреса электронной почты; позволяет отправлять пользователю
   сообщение по выбранному шаблону.

Результаты отправляются на список адресов электронной почты, заданный для каждой
формы. Если форма содержит поле типа email с выбранным шаблоном, сообщение
отправляется также на указанный в нём адрес.

## Настройка плагина

### Создание формы

При нажатии «Создать новую форму» создаётся пустая форма с ID `newform`.
Рекомендуется заменить этот идентификатор перед использованием.

### Использование формы

Чтобы форма была доступна посетителям, включите флаг «Активна» при её редактировании.

### Собственные шаблоны

Для каждой формы можно создать собственный шаблон. Он может храниться в теме сайта
или в каталоге плагина:

- `templates/<имя темы>/plugins/feedback/custom/<имя шаблона плагина>/`
- `engine/plugins/feedback/tpl/custom/<имя шаблона>/`

Используемый шаблон выбирается в настройках плагина.

### `mail.html.tpl` и `mail.text.tpl`

#### Шаблоны email-сообщения

В шаблонах доступны следующие TWIG переменные:

- `form` — параметры формы:
  - `form.id` — ID формы;
  - `form.title` — название;
  - `form.description` — описание.
- `flags` — набор флагов:
  - `flags.link_news` — признак наличия прикреплённой новости.

Для отображения полей формы доступны следующие переменные:

- `entries` — массив полей в порядке, заданном в настройках формы:
  - `entries[x].id` — ID поля;
  - `entries[x].title` — заголовок поля;
  - `entries[x].value` — значение, введённое пользователем.
- `values` — значения полей; ключ — ID поля, значение — введённые данные.

В случае наличия прикрепленной новости доступны также переменные:

- `news.id` — ID новости;
- `news.title` — заголовок новости;
- `news.url` — URL новости.


## Привязка формы к новостям

Форма может работать в трёх режимах:

- без привязки;
- привязка возможна;
- привязка обязательна.

Для привязки к новости передайте в URL формы GET-параметр `linked_id` со значением
ID новости. При размещении ссылки в `news.short.tpl` или `news.full.tpl` это
параметр `linked_id={news-id}`.

Пример URL формы по умолчанию:
`/plugin/feedback/?id=9&linked_id={news-id}`.



## Использование плагина

При заходе в режим редактирования формы обратной связи вы увидите URL, по которому данная форма будет доступна.
