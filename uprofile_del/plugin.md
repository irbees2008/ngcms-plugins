# Удаление профиля

Плагин позволяет зарегистрированному пользователю удалить свой профиль с сайта.

## Возможности

- Пользователь может удалить свой профиль, но не может удалять чужие профили.
- Гости не могут удалять профили.
- Администратору запрещено удалять собственный профиль.
- Поддерживаются хлебные крошки (breadcrumbs) и метаданные страницы.
- При удалении профиля также удаляются данные личных сообщений и сессия авторизации.
