# CSV IMPORT — Импорт товаров из CSV / YML

**Версия:** 2.1.0  
**Зависимость:** `xfields` (необязателен; нужен для дополнительных полей).

## Описание

Плагин позволяет импортировать товары (новости NGCMS) из CSV-файлов с гибким
маппингом колонок. Поддерживает заполнение доп. полей xfields, обновление
существующих записей, кодировки UTF-8 и Windows-1251.

## Установка

1. Установите плагин через панель администратора.
   Дополнительные таблицы не создаются.
2. Убедитесь, что папка `engine/plugins/csv_import/upload/` существует
   и доступна для записи (создаётся автоматически).
3. Перейдите: Плагины → csv_import → Настройки.

## Процесс импорта

1. **Загрузка:** выберите CSV-файл в форме.
2. **Сопоставление:** нажмите «Настроить импорт», выберите разделитель, укажите,
   есть ли строка заголовков, и настройте соответствие колонок.
3. **Запуск:** нажмите «Запустить импорт». В результате отображаются числа
   созданных и обновлённых записей, а также ошибок.

## Формат CSV-файла

- Кодировка: UTF-8 или Windows-1251 (определяется автоматически).
- Разделитель: `;`, `,` или табуляция.
- Первая строка может содержать заголовки колонок для автоматического сопоставления.
- Максимальный размер файла ограничен настройкой PHP `upload_max_filesize`.

Пример с разделителем `;`:

```csv
title;price;weight;color;short_story
Кроссовки Nike;3500;0.8;белый;Лёгкие беговые кроссовки
Кеды Vans;2100;0.6;чёрный;Классические кеды
```

## Сопоставление колонок

Для каждой CSV-колонки выберите поле назначения:

| Поле | Назначение |
| --- | --- |
| `title` | Заголовок (обязательно). |
| `short_story` | Краткое описание. |
| `full_story` | Полное описание. |
| `alt_name` | URL; если не задан, генерируется из заголовка. |
| `category` | ID категории; заменяет категорию по умолчанию. |
| `tags` | Теги и ключевые слова. |
| `xf_NAME` | Поле `xfields` с именем `NAME`, например `xf_price`, `xf_weight` или `xf_color`. |
| `skip` | Пропустить колонку. |

Если первая строка содержит заголовки, совпадающие с именами стандартных полей или
`xfields`, соответствие назначается автоматически.

## Параметры импорта

- **Категория по умолчанию** — назначается записям без поля `category` в CSV.
- **Статус** — опубликована (`approve=1`) или скрыта (`approve=0`).
- **Главная страница** — показывать запись на главной (`mainpage=1`) или нет.
- **Обновлять существующие** — при совпадении `alt_name` обновлять заголовок,
  описания, теги и `xfields`; если выключено, всегда создаётся новая запись.

## Управление файлами

- Загруженные файлы хранятся в `engine/plugins/csv_import/upload/`.
- Разрешены файлы `.csv`, `.yml` и `.xml`.
- Файлы можно удалять из панели управления.
- Старые файлы не удаляются автоматически.

## Ограничения CSV-импорта

- Изображения не импортируются из CSV; добавьте их вручную или используйте YML.
- Для импорта `xfields` поля должны быть предварительно созданы в настройках плагина.
- Должна быть доступна функция `xf_saveNewsData()` (плагин `xfields` установлен).

## Импорт YML (Яндекс.Маркет)

Поддерживается формат `yml_catalog` (Яндекс.Маркет).

1. Загрузите файл `.yml` или `.xml`.
2. Нажмите «Настроить YML импорт».
3. Настройте сопоставление полей и категорий.
4. Запустите импорт.

| Элемент YML | Поле назначения |
| --- | --- |
| `<name>` | Заголовок (`title`). |
| `<price>` | `xfields`, например `xf_price`. |
| `<oldprice>` | `xfields`, например `xf_oldprice`. |
| `<description>` | Краткое или полное описание. |
| `<vendor>` | `xfields`, например `xf_brand` или `xf_vendor`. |
| `<model>` | `xfields`, например `xf_model`. |
| `<barcode>` | `xfields`, например `xf_barcode`. |
| `<vendorCode>` | `xfields`, например `xf_articul` или `xf_vendorCode`. |
| `<count>` | `xfields`, например `xf_count`. |
| `<weight>` | `xfields`, например `xf_weight`. |
| `<param name="X">` | `xfields`, автоматическое сопоставление по имени. |
| `<categoryId>` | Категория NGCMS через сопоставление. |
| `<picture>` | Загрузка изображения. |

Сопоставление автоматически предлагает варианты на основе названий полей `xfields`.

## Загрузка изображений из YML

Изображения из `<picture>` скачиваются на сервер и связываются с товаром через
`xfields` типа `images`.

Требования:

- В `xfields` должно быть поле типа `images`, например `gallery` или `photos`.
- PHP должен иметь доступ к интернету через `file_get_contents` или cURL.
- Каталог `uploads/dsn/` должен быть доступен для записи.

Параметры импорта изображений:

- **Загружать изображения** — включить или выключить загрузку.
- **XField для изображений** — поле типа `images`.
- **Макс. изображений на товар** — от 1 до 10; по умолчанию 3.

Файлы сохраняются в `uploads/dsn/{dsnPath}/{имя_newsId_hash.ext}`, а запись
добавляется в таблицу `{prefix}_images` с `plugin='xfields'`. При повторном импорте
файлы не дублируются; изображения доступны в шаблонах через механизм `xfields images`.

Пример структуры YML:

```xml
<offer id="1" available="true">
  <name>Куртка зимняя</name>
  <price>4500</price>
  <picture>https://example.com/img/jacket_1.jpg</picture>
  <picture>https://example.com/img/jacket_2.jpg</picture>
  <param name="Цвет">Чёрный</param>
  <param name="Размер">M, L, XL</param>
</offer>
```

## Сопоставление категорий YML

В форме импорта показываются категории из YML. Для каждой выберите соответствующую
категорию NGCMS. Если названия совпадают без учёта регистра, соответствие
определяется автоматически.

## Пример: подготовка CSV для импорта каталога

Предположим, что в `xfields` настроены поля `price`, `brand`, `material` и `size`.

```csv
title;alt_name;short_story;price;brand;material;size;tags
Куртка зимняя;kurtka-zimnyaya;Тёплая куртка на синтепоне;4500;Nike;полиэстер;M,L,XL;куртка зима одежда
Джинсы прямые;dzhinsy-pryamye;Классические прямые джинсы;2300;Levi's;деним;28,30,32;джинсы брюки
```

Сопоставление колонок:

- 0 → `title`
- 1 → `alt_name`
- 2 → `short_story`
- 3 → `xfields: price`
- 4 → `xfields: brand`
- 5 → `xfields: material`
- 6 → `xfields: size`
- 7 → `tags`
