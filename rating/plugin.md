# Рейтинг новостей

Плагин позволяет пользователям оценивать новости по шкале от 1 до 5.

Плагин поддерживает мультискины, т.е. уже в поставку плагина входит сразу
несколько вариантов оформления рейтингов.

Информация о проголосовавшем пользователе сохраняется в cookie его браузера,
поэтому при желании подобный счётчик можно очень просто "накрутить".
Положительным моментом такого подхода является более высокое быстродействие.

> **Внимание.** Шаблоны по умолчанию используют JavaScript и AJAX и требуют
> включённого режима ЧПУ. Можно создать собственный шаблон без этих технологий.

Файлы шаблонов находятся в `./tpl/skins/НАЗВАНИЕ_СКИНА/`.

## Используемые шаблоны

- `rating.css` — стили рейтинга.
- `rating.tpl` — шаблон, отображаемый после голосования. Доступные переменные:
  - `{tpl_url}` — URL каталога с файлом стилей рейтинга;
  - `{home}` — URL главной страницы сайта;
  - `{rating}` — текущий рейтинг от 1 до 5;
  - `{votes}` — количество проголосовавших.
- `entries.tpl` — строки информационного блока. Доступные переменные:
  - `{link}` — ссылка на новость;
  - `{title}` — заголовок новости;
  - `{views}` — количество просмотров новости.

## Возможности

- Кеширование.
- Размещение шаблонов плагина внутри шаблона сайта.
