# Статистика сайта

Плагин `site_stats` выводит количественную статистику сайта: количество новостей, пользователей, страниц и другие показатели. Во избежание конфликтов и лишних запросов к базе данных отключите `k_online`, `stats` и другие версии плагина статистики.

**Версия движка, на которой тестировался плагин:** 0.9.5 Release + GIT 20170301.

## Возможности

- Показывает, сколько дней существует сайт.
- Отображает количество статических страниц, категорий, новостей, неопубликованных новостей, комментариев, загруженных изображений и файлов, зарегистрированных, неактивных и забаненных пользователей.
- Показывает статистику пользователей онлайн, включая гостей и основных поисковых ботов.
- Позволяет настраивать параметры в админке и шаблоне.
- Поддерживает кеширование и обновление количественной статистики раз в сутки по CRON.

## Установка и настройка

1. Распакуйте архив.
2. Скопируйте папку `site_stats` в `engine/plugins/`.
3. В админке откройте управление дополнениями, установите и включите `site_stats`.
4. В конфигураторе плагина выберите параметры и настройте кеширование, затем сохраните изменения.
5. Настройте шаблон `engine/plugins/site_stats/site_stats.tpl`.

## Шаблон

`site_stats.tpl` — шаблон информационного блока. Поддерживаемые переменные:

- `{{ stats }}` — массив общей статистики сайта.
- `{{ online }}` — массив статистики пользователей онлайн.

## Вывод в `main.tpl`

```twig
{% if pluginIsActive('site_stats') %}
  {{ site_stats }}
{% endif %}
```

Шаблоны плагина можно размещать внутри шаблона сайта; параметры отображения выбираются отдельно.
