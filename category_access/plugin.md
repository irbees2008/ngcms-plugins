# Управление доступом к категориям

Плагин управляет доступом пользователей к категориям с учётом групп пользователей,
категорий, закреплённых за отдельными пользователями, и общих категорий.

## Особенности

- Плагин не выполняет дополнительных запросов к базе данных.
- При ограничении доступа пользователю выводится соответствующее сообщение. Его
  текст можно изменить в настройках плагина в административной панели.
- Плагин обрабатывает страницы со смешанными новостями из разных категорий. При этом
  на странице может отображаться меньше новостей, чем задано в настройках: SQL-запросы
  не изменяются, а новости из закрытых категорий скрываются при выводе.

## Совместимость

- Версия ядра NG CMS должна соответствовать значению `MinEngineBuild` в файле `version`.
- PHP 7.4–8.4. Используется `__construct`, устаревший конструктор с именем класса удалён.

## История изменений

### Версия 0.03

- Удалён устаревший конструктор с именем класса; оставлен `__construct` для PHP 7.4–8.4.
- Уточнены требования к версии PHP в `version` и `readme`.

### Версия 0.02

- Обеспечена совместимость с PHP 7/8: добавлены `__construct` и явные свойства класса.
- Повышена стабильность административной части при пустых настройках и неизвестных действиях.
- Исправлены текстовые описания.
