# Архив сайта

Плагин позволяет на сайте отображать информационный блок-архив новостей.
В блоке показывается список месяцев в которые на сайте создавались новости.

> Версия 0.10: интегрирована ng-helpers v0.2.2 для улучшения производительности и безопасности.

Для работы плагина используется единый TWIG шаблон (по умолчанию archive.tpl).

## Требования

- NGCMS >= 0.9.3
- PHP >= 7.0
- ng-helpers >= 0.2.2 (для улучшенного кеширования и валидации)

## Переменные шаблона

- `{{tpl_url}}` — путь к текущему активному шаблону сайта.

Цикл `{% for entry in entries %}...{% endfor %}` выводит строки информационного блока.
Внутри цикла доступны:

- `{{entry.link}}` — ссылка на новости за месяц;
- `{{entry.title}}` — название месяца и год;
- `{{entry.cnt}}` — количество новостей за месяц (если счётчик включён в настройках);
- `{{entry.ctext}}` — текстовое описание количества из `main.ini`, переменная `counter.case`
  (если текстовый счётчик включён);
- `entry.counter` — условие для отображения содержимого счётчика новостей.

## Использование в шаблонах

1. При автоматическом запуске переменная `{plugin_archive}` в `main.tpl` выводит блок архива.
2. Для ручного вызова используйте Twig-функцию `callPlugin()`:

   ```twig
   {{ callPlugin('archive.show', {'maxnum' : 12, 'counter' : 1, 'tcounter' : 1, 'template': 'archive_twig'}) }}
   ```

   Пример вызова без указания шаблона:

   ```twig
   {{ callPlugin('archive.show', {'cacheExpire': 60 }) }}
   ```

Параметры `archive.show`:

| Параметр | Описание |
| --- | --- |
| `maxnum` | Количество отображаемых месяцев. |
| `counter` | Показывать счётчик новостей. |
| `tcounter` | Показывать текстовое описание количества. |
| `template` | Имя шаблона. |
| `cacheExpire` | Время кеширования; по умолчанию `0`. |

## Возможности и кеширование

- Генерация блока через Twig-функцию `callPlugin()`.
- Кеширование с автоматическим управлением TTL через ng-helpers v0.2.2.
- Проверка `maxnum` (1–50) и TTL (0–86400 секунд) с помощью `clamp()`.
- Санитизация параметра `template` с помощью `sanitize()`.
- Логирование операций в `engine/logs/archive.log`.
- Шаблоны плагина можно разместить внутри шаблона сайта.

Подробности: `engine/plugins/archive/CHANGELOG_NGHELPERS.md`.
