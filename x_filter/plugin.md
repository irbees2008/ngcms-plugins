# Фильтр новостей

Плагин `x_filter` выводит форму фильтрации новостей по категориям и полям плагина `xfields`. На отдельной странице он показывает отфильтрованные результаты и поддерживает полнотекстовый поиск по заголовку и содержимому новости.

## Требования

- Установленный и активный плагин `xfields`.
- Поля `xfields` должны быть настроены для хранения в новостях.
- Для полнотекстового поиска плагин добавляет индекс `FULLTEXT` по полям `title` и `content` таблицы новостей.

При установке плагина создаётся индекс `search` по `title` и `content`; при удалении плагина он удаляется.

## Установка

1. Установите и включите `xfields`.
2. Установите и активируйте `x_filter` в админ-панели.
3. Настройте плагин в разделе его настроек.
4. Убедитесь, что нужные поля `xfields` включены для хранения в новостях.
5. Добавьте переменную формы в шаблон сайта, например в `main.tpl`:

   ```twig
   {{ x_filter_form }}
   ```

6. Откройте страницу фильтра, чтобы просматривать результаты. При стандартных ЧПУ адрес плагина формируется как `/plugin/x_filter/`.

Форма также доступна как переменная `x_filter_form` на главной странице. Страница плагина выводит результаты фильтрации в основном блоке.

## Настройки

### Фильтр

- **Категории, которые не нужно отображать (`skipcat`)** — ID исключаемых категорий через запятую. Дочерние категории исключённых категорий также скрываются. Пустое значение оставляет все категории доступными.
- **Включить выборку из всех категорий (`showAllCat`)** — разрешает выбирать все категории в списке.
- **Порядок вывода (`order`)** — сортировка по умолчанию:
  - `id_desc`, `id_asc` — по ID, убывание или возрастание.
  - `postdate_desc`, `postdate_asc` — по дате добавления, убывание или возрастание.
  - `title_desc`, `title_asc` — по заголовку, убывание или возрастание.
- **Количество новостей на странице (`showNumber`)** — размер страницы результатов. В форме настроек указано значение по умолчанию 10.

### Шаблоны

- **Источник шаблонов (`localsource`)**:
  - `0` — шаблон сайта; если шаблон недоступен, используется каталог плагина.
  - `1` — каталог плагина.
- В шаблонах сайта используйте каталог `templates/<тема>/plugins/x_filter/`; файлы плагина находятся в `engine/plugins/x_filter/tpl/`.
- Используются `filter_form.tpl`, `search_form.tpl`, `x_filter.css` и `x_filter.js`.

### Встраивание CSS, JavaScript и метаданных

- **`use_css`** — подключать ли CSS файл фильтра.
- **`use_js`** — подключать ли JavaScript файл фильтра. Скрипт отправляет форму выбора категории при изменении списка и раскрывает/сворачивает блоки полей.
- **`canonical`** — добавлять каноническую ссылку на страницу фильтра.
- **`meta_robots`** — добавлять `noindex, follow` для страницы фильтра.

Параметры `canonical` и `meta_robots` применяются к странице плагина.

### Кеширование

- **`cache`** — включить кеширование.
- **`cacheExpire`** — срок кеширования в секундах; значение по умолчанию в настройках — 60 секунд.

Кешируются списки уникальных значений полей, используемые в вариантах фильтра.

## Как устроен фильтр

- Категория передаётся параметром `catid`. Если он не указан, плагин пытается определить текущую категорию страницы.
- Дополнительные поля передаются с именами `x_<ID_поля>`, например `x_price`.
- Поиск передаётся параметром `s` и выполняется по заголовку и содержимому новости с помощью полнотекстового поиска MySQL в Boolean Mode.
- Сортировка передаётся параметром `order`.
- Номер страницы передаётся параметром `page`.
- Пустые значения дополнительных полей не добавляются в условия фильтра.

Для фильтра доступны поля `xfields` типов `text` и `select`, сохранённые в данных новости. Значения текстового поля формируют список вариантов автоматически из уникальных значений в новостях; рядом с каждым значением показывается число новостей. Варианты поля `select` берутся из его настроек. Для необязательного поля добавляется пустой вариант («Все»).

## Примеры запросов

Адреса ниже показывают имена и значения параметров; используйте URL страницы плагина, подходящий для конфигурации ЧПУ вашего сайта.

Фильтр по категории:

```text
/plugin/x_filter/?catid=3
```

Фильтр по категории и значению поля `price`:

```text
/plugin/x_filter/?catid=3&x_price=10000
```

Поиск по заголовку и содержимому среди выбранной категории:

```text
/plugin/x_filter/?catid=3&s=камера
```

Фильтр по полю, полнотекстовый поиск и сортировка по дате публикации:

```text
/plugin/x_filter/?catid=3&x_gender=Женский&s=пальто&order=postdate_desc
```

Переход на вторую страницу результатов:

```text
/plugin/x_filter/?catid=3&x_price=10000&order=postdate_desc&page=2
```

Допустимые значения `order`: `id_desc`, `id_asc`, `postdate_desc`, `postdate_asc`, `title_desc`, `title_asc`. Форма шаблона по умолчанию предлагает «По умолчанию» (`id_desc`), сортировку по названию (`title_asc`) и по дате (`postdate_asc`); остальные варианты можно выбрать в настройках или передать параметром `order`.

## Шаблоны

### `filter_form.tpl`

Шаблон формы фильтрации. Получает список категорий `catlist`, ссылку формы `form_action`, текущую сортировку `order` и переменные для полей XFields. В шаблоне из комплекта для вывода полей предусмотрены `x_price`, `x_gender` и `x_year`. Для каждого доступного поля передаются:

- `title` — название поля.
- `input` — HTML-список вариантов.
- `active` — выбран ли фильтр по этому полю.

Если у вас другие ID полей, добавьте аналогичные условные блоки для нужных ID. Например:

```twig
{% if x_brand %}
    <div class="xf__item {{ x_brand.active ? 'active' : '' }}">
        <label class="xf__title">{{ x_brand.title }}</label>
        <div class="xf__body">{{ x_brand.input }}</div>
    </div>
{% endif %}
```

Поле категории отправляется как `catid`. Поля сортировки отправляются как `order`.

### `search_form.tpl`

Шаблон поиска по результатам. Поле `s` содержит поисковый запрос; переменная `count` — количество найденных результатов.

### `x_filter.css` и `x_filter.js`

CSS задаёт оформление формы. JavaScript подключается при включённой настройке `use_js`; он автоматически отправляет форму при изменении списка категорий и позволяет раскрывать и сворачивать группы полей.

## Локализация

Языковые файлы плагина расположены в `lang/russian/` и `lang/english/`:

- `frontend.ini` — подписи и сообщения на пользовательской стороне.
- `backend.ini` — названия и описания настроек в админ-панели.

## Примечания

- Плагин использует `news_showlist()` движка для выборки новостей и стандартный механизм постраничной навигации.
- Поиск `s` требует установленного полнотекстового индекса, создаваемого при установке плагина.
- При деинсталляции удаляется индекс `search` таблицы новостей.
