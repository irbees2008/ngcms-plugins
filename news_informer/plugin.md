# Информер новостей

Плагин выводит на внешних сайтах блок последних новостей с заголовками, изображениями, категориями и датами. Информер можно встроить с помощью JavaScript или iframe; также доступен Twig-вызов.

## Настройка

- `count` — количество новостей (от 1 до 20; по умолчанию 5).
- `mode` — режим работы: автоматический вывод или Twig.
- `localsource` — источник шаблонов: шаблоны сайта или плагина.
- `cache` и `cacheExpire` — настройки кеширования и срок его действия в секундах.

## Встраивание на внешний сайт

Код для вставки формируется в настройках плагина. Доступны два варианта.

### JavaScript

```html
<script src="URL_ИНФОРМЕРА"></script>
```

### Iframe

```html
<iframe src="URL_ИНФОРМЕРА&mode=html" width="300" height="500" frameborder="0" scrolling="auto"></iframe>
```

## Использование в Twig

Плагин регистрирует Twig-функцию `news_informer.show`. Например, чтобы вывести пять новостей:

```twig
{{ callPlugin('news_informer.show', {count: 5}) }}
```

Функция также принимает параметры `cacheExpire` (срок кеширования в секундах) и `template` (имя шаблона).

## Данные шаблона

Информер передаёт шаблону массив `entries`, в котором каждый элемент содержит:

- `link` — ссылка на новость;
- `title` — заголовок;
- `image` — URL изображения или пустую строку;
- `category.name` — название категории;
- `category.link` — ссылка на категорию;
- `date` — дата публикации в формате `дд.мм.гггг чч:мм`.

Также доступны переменные `tpl_url`, `home` и `lang` с текстами для информера.
