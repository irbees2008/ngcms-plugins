# Доска объявлений

## Возможности

1. Зарегистрированные пользователи могут добавлять, редактировать и удалять объявления.
2. Можно разрешить добавление объявлений гостям.
3. Поддерживается CAPTCHA reCAPTCHA.
4. Есть фильтр ссылок при добавлении объявления.
5. На главной странице можно выводить последние, случайные и часто просматриваемые объявления.
6. Объявления автоматически снимаются по истечении срока действия через CRON; срок действия можно продлить.
7. Поддерживаются ЧПУ.
8. Кешируются главные блоки, общий счётчик объявлений и дерево категорий.
9. В шаблонах используется Twig.
10. Можно создавать вложенные категории любой глубины и выводить их дерево с отступами.
11. Поддерживается статистика просмотров с режимами: отключено, включено и отложенный подсчёт.
12. В архиве есть демонстрационный шаблон; для изображений можно использовать карусель.
13. При добавлении объявления поддерживаются BB-коды.
14. Есть собственный поиск объявлений.
15. В админке можно редактировать и удалять объявления, а также добавлять, редактировать и удалять категории.

## Страницы и шаблоны

После установки плагина и включения ЧПУ доступны следующие страницы:

| URL | Назначение | Шаблон |
|---|---|---|
| `/zboard/` | Главная страница плагина | `zboard.tpl` |
| `/zboard/cat/X/` | Страница категории | `zboard.tpl` |
| `/zboard/show/X/` | Просмотр объявления | `show_zboard.tpl` |
| `/zboard/send/` | Добавление объявления | `send_zboard.tpl` |
| `/zboard/search/` | Поиск объявлений | `search_zboard.tpl` |
| `/zboard/list/` | Список объявлений пользователя; только для зарегистрированных | `list_zboard.tpl` |
| `/zboard/edit/X/` | Редактирование объявления; только для зарегистрированных | `edit_zboard.tpl` |
| `/zboard/vip/X/` | Оплата VIP-размещения; доступна автору объявления | `vip_zboard.tpl` |
| `/zboard/pay/` | Служебный обработчик платежей и callback; не предназначен для прямого просмотра | — |

В документации пути шаблонов приведены относительно `templates/mangguo/plugins/zboard/`. Файл `variables.ini` в этой папке задаёт параметры постраничной навигации. Шаблон `no_access.tpl` отображает сообщение, если у пользователя нет прав на страницу, например при попытке изменить чужое объявление.

## Вывод блоков в `main.tpl`

Общий счётчик объявлений:

```twig
{{ callPlugin('zboard.show_entries_cnt') }}
```

Дерево категорий:

```twig
{{ callPlugin('zboard.show_catz_tree') }}
```

Оба блока кешируются; запросы к БД выполняются при изменении объявлений или категорий.

Для вывода списка объявлений используйте `zboard.show`:

```twig
{{ callPlugin('zboard.show', {
    'number': 10,
    'mode': 'last',
    'cat': '1,2,3',
    'template': 'block_zboard_last',
    'cacheExpire': 360
}) }}
```

Параметры блока:

- `number` — количество объявлений.
- `mode` — режим сортировки: `last` (по дате активации или редактирования), `view` (по просмотрам), `rnd` (случайный порядок).
- `cat` — ID одной или нескольких категорий через запятую. Если параметр не задан, используются все категории.
- `template` — шаблон блока в `templates/mangguo/plugins/zboard/block/` или `engine/plugins/zboard/tpl/block/`.
- `cacheExpire` — срок кеширования в секундах.

## Условия Twig

В `main.tpl` можно показывать блоки в зависимости от состояния плагина и текущей страницы:

```twig
{% if pluginIsActive('zboard') %}XXX{% endif %}
{% if isHandler('zboard') %}XXX{% endif %}
{% if isHandler('zboard:list') %}XXX{% endif %}
{% if isHandler('zboard:edit') %}XXX{% endif %}
{% if isHandler('zboard:send') %}XXX{% endif %}
{% if isHandler('zboard:show') %}XXX{% endif %}
{% if isHandler('zboard:search') %}XXX{% endif %}
```

`zboard` соответствует страницам плагина, а обработчики `list`, `edit`, `send`, `show` и `search` — соответствующим страницам или группам страниц.

## VIP-размещение и оплата

VIP-размещение можно оплатить через Pay2Pay и/или Robokassa. Стоимость и срок тарифа в днях задаются в админке: «ZBoard» → «Прайс». После успешной оплаты выставляются `vip_added` и `vip_expired`, объявление активируется.

Маршруты:

- `/zboard/vip/X/` — выбор тарифа и платёжной системы, запуск оплаты.
- `/zboard/pay/` — служебный обработчик и callback URL.

Если настроена одна платёжная система, она выбирается автоматически и список выбора скрыт. Если настроены обе, на странице VIP-размещения появляется список «Платёжная система».

### Robokassa

1. В админке откройте «Плагины» → «ZBoard» → «Настройки» → «Настройки Robokassa» и укажите:
   - логин магазина (`MerchantLogin`);
   - пароль № 1 (`Pass1`);
   - пароль № 2 (`Pass2`);
   - тестовый режим, если требуется.
2. В кабинете Robokassa задайте URL:

   | Назначение | URL |
   |---|---|
   | Fail URL | `http://<ВАШ_ДОМЕН>/plugin/zboard/pay/?result=1` |
   | Result URL | `http://<ВАШ_ДОМЕН>/plugin/zboard/pay/?result=2` |
   | Success URL | `http://<ВАШ_ДОМЕН>/plugin/zboard/pay/?result=3` |

3. Подпись ResultURL проверяется по формуле `MD5(OutSum:InvId:Pass2)` в нижнем регистре.

Для отладки входящие уведомления записываются в `/engine/plugins/zboard/upload/robokassa_result.log`. Лог содержит IP, параметры запроса, полученную и вычисленную подписи, а также результат обработки.

### Pay2Pay

1. В админке откройте «Плагины» → «ZBoard» → «Настройки» → «Настройки Pay2Pay» и укажите:
   - идентификатор магазина (`merchant_id`);
   - секретный ключ (`secret_key`);
   - скрытый ключ (`hidden_key`);
   - тестовый режим, если требуется.
2. Обработчик callback использует XML и подпись `base64(md5(HIDDEN_KEY + XML + HIDDEN_KEY))`.

### Настройка тарифов

Стоимость задаётся в рублях, срок — в днях. Рекомендуется назначать тарифам уникальную стоимость: сопоставление суммы используется для определения срока.
